# 余積（空白）の解決

alpha1 で、空白で並べた項（余積）をどう読むかの今の答え。前の答えと決めた経緯は git の履歴にある。

---

## 0. 前置き

### 0.1 線の引き方

- 確信度は、その規則が利用者の意図と法則に合っている見込み。91% 以上だけを実装し、90% 以下は名指しで断るか、§5 の未決に置く。
- 門（名指しで断る規則）の確信度は、その形を断ってよい見込み（R22）。
- 広い形で割れても、割れない狭い形を取り出せるときは、狭い形に確信度を付け、残りを門か未決に回す。

### 0.2 証拠の印

| 印 | 意味 |
|---|---|
| U | 利用者の言葉 |
| U〔答え〕 | Claude の案への利用者の答え |
| U〔貼〕 | 利用者が貼った Claude 側の文。U より弱い |
| D | 文書・コード・走らせた結果。alpha の値は根拠にしない |
| R | 主の Claude の読み |

規則の見出しには印だけを書く。逐語と日時は履歴にある。

### 0.3 綴り

- `_` は id。口に置けば穴（その口の恒等射）、口の外では恒等射、点なしでは席。
- `!_` は void。置かれた演算の単位。源の `!_` は計算から生まれた物だけ。
- 手で書いた `!_`・書いた空の器・見える範囲に定義の無い名前は、読む段で断る（R138）。
- `!!` は bitNOT。

### 0.4 圏論で言えること

- 隣り合う2項の種類の対は、値値・関数関数・関数値・値関数の4つで尽きる。値値は構築（零対象つきの標準の射 A⊔B→A×B、同型なら双積）、関数関数は合成、関数値は適用（評価射）。値関数は読みを持たない（R47）。
- 構築と合成は同じ項を取り合わず、どちらも種類を変えないので、順が要らない。
- 構築と適用の上下は圏論からは出ない。カリー化の随伴 Hom(X×A,B)≅Hom(X,B^A) で、アリティどおりなら値は同じ。割れるのは実引数の数がアリティと合わない時で、そこは利用者の約束（余りは後ろに積む、R35）で決める。
- 零対象を持つカルテシアン閉圏は自明なので、「構築＝双積」と「適用＝同じ積の評価射」は同じ積に乗らない。値＝大域元と `!_`＝零対象も同じ圏に並べられない（1≅0 になる）。だから値を A、関数を L という種類として扱うだけにした。
- `!_` は零対象。関数の顔は不動点（何を受けても `!_`）で、源には書かない。即値の顔は、並びの要素・`,`・`|`・`;`・算術とビットの被演算子・値の口・点なしの比べの積で、置かれた演算の単位（0⊕A≅A）。中置の比べと `&` の被演算子では `!_` を返す。場所の顔（`#` の左・`@` の先・`$` の先・参照の口）は、書けば捨て、読めば空。
- `_` は id。穴は法則でなく記法で、口に恒等射を置いたまま残りを埋める λ 抽象（`f _ 3` は `a ? f a 3`。カリー化の随伴の自然同型）。
- 恒等射の単位律と「恒等射は並び全体を受ける」（R29）が割れる所は、単位律の側（R126）。

## 1. 入力と出力

### 1.1 入力

- 前段は1行を語の平たい配列で返す。前置・後置の印は核と別の語として並ぶ。綴りから意味への写しは、解く段の tokenize の1か所。
- 語の見分け：前置の印は記号＋末尾 `_`、後置の印は `_`＋記号1つ、`"_"` だけは id、名前は `<…>`、囲みは配列（BRACKET_ など）、中置は下線を含まない記号、字面はそれ以外。

### 1.2 前提にする段

- **P1**：段12〜25（範囲・比較・算術・`'`・中置 `@`・ビット・後置・前置）は項の中へ先に畳む。段1〜9（改行・`:`・`?`・中置 `#`・`;`・`|`・`&`・`==`・`!==`・`,`）は並びを切る。P1 は operator_table.js だけで決まる。
- **P2**：ファイルのいちばん外の定義を、順序に依らず先に全部集める。範囲ごとに名前1つに種類1つ。同じ範囲の同名は name-duplicate、値の定義を含む種類の輪は name-cycle で断る。見える範囲に定義の無い名前は name-undefined（呼ばない本体と解かない所も、R21）。
  - 隠し（仮引数とファイルの定義か外の仮引数が同じ名前）は断らない。内側が勝ち、information の name-shadow で知らせる（R133）。
  - 取り込み（後置 `@`）のある範囲では、表に無い名前を種類の未知にする。2項以上の並びに置けば G7（§5 Q10）。
  - 関数の本体の字下げの `:` の行は枝で、名前を定義しない（R128）。本体の中の名前は、仮引数かファイルの定義として内から引く。括りの中の行と構造体のブロックの行の名前は欄（local-field）。
- **P3**：解く並びは `:` の右・`?` の右・括りの各行・字下げのブロックの各行。本体の枝の条件は1項でも `&` の左と同じに解く。定義・欄・既定値の左と `?` の左は解かない。
- 機械の前提は UEFI を抜けた後（CPU とメモリは使え、割り込みとタイマは止まっている）。解決器は機械を見ないので、木は変わらない。

### 1.3 出力の木

| 節 | 意味 | 種類 |
|---|---|---|
| `(construct a b …)` | 2項以上を書いた順に並べる | A |
| `(construct (apply h x1…xn) xn+1 …)` | 実引数がアリティより多い適用。前から n 個を当て、余りを後ろに積む（R35） | A |
| `(compose f g …)` | 2項以上を書いた順（＝実行の順）に並べる | L |
| `(apply h x)` | 頭 h と実引数 x（1項か construct 1つ） | §3.4 |
| `(apply g (construct (apply f x…) y…))` | 合成 `f g` の g が並びの項も受けた適用。各関数が受けた物が見える入れ子 | §3.4 |
| `(unit X)` | 評価する所の終わりに残った未評価のラムダ X と、値の上に積まれて閉じた関数（`$[…]` の中身を除く）。値は `!_`。X が恒等射でなければ leftover-lambda | A |
| `(? [$p0 …] (apply h …))` | 穴の書き換え。`$p0` は衝突しない生成名 | L |
| `(? [仮引数] (inst 形 本体) …)` | 括りの関数の、渡された物の生まれ（形）ごとの実体（R24） | L |
| `(? [仮引数] (defer {本体}))` | 一度も呼ばれない括りの関数。本体は書いたまま読まない（R25） | L |

- 葉は項そのもの（畳んだ中置・括り・印つきの項・名前・字面）。項が1つの並びは、その項そのもの。
- `construct` の子の `construct` と、`compose` の子の `compose` は開いて並べる（R8）。括りと囲みは開かない。
- 括らない `,` の鎖の恒等射の葉は単位で消え、残った因子の木が答え（R61）。因子が残らなければ空の積で、`!_` と分かる辺（R137）。否定の点なし `(!_)` は関数で、消えない。
- 節の印は種類と残りのアリティだけ。
- inst の形の綴り：A・N・L・U・A(U)、構造体は欄の順の `{k:L …}`、List は `[A…]`。仮引数が2つ以上なら空白で並べる。400 字で切る（鍵は切らない）。

## 3. 結び方

### 3.1 表

| 左 | 右 | 結び | 段 |
|---|---|---|---|
| A | A | construct | 10.3（10.4・10.5 も同じ族） |
| L | L | compose | 10.2 |
| L | A | apply(左, 右) | 10.1 |
| A | L | 読みは無い。右の関数は積まれる（R47） | |

concat と unshift・push の違いは値の段（構造は保つ）。

### 3.2 順

強さの順は無い。余積は1つの演算子で左結合（R40）。並びは左から1項ずつ畳み、次の項はいちばん上の項とだけ結ぶ。

### 3.3 手順

0. **項を作る**：前置の印・核・後置の印を1項に寄せ、葉の種類を付ける（§2）。
   - `$` の項はここで決める（R99〜R101・R49・R56・R57）。
   - 中置の項で、番地の点と差に R62 を当てる。関数を指す番地を値の演算子か比べに置けば G7。
   - `!_` と分かる値（R91・R115・R102 の名前とそれを括った物）は印 zero を持ち、括りの関数の実体へ持ち越す（R49）。
   - 値の演算子の被演算子と値の印の核に丸ごと残った関数は、評価する所で `!_`（R87）。長さ 0 と分かる流れは `!_` と同じ印（R84）。
1. **前検査**：後置 `~` の項の中身に L か未知が見えれば G7。名前の読みが決まらない項が2項以上の並びにあれば G7。ほかの未知な葉は断らない（R120）。
2. **`_` の穴**：並び全体と、値の後ろに積まれた関数 F から終わりまで（`F Y`）の並びを見て、R16・R34 の穴と G13 を読む（§3.5）。
   - 閉じた頭の後ろの口の外の `_` は恒等射（R69・R89）。
   - `_` 1つの並びは、`,` の被演算子なら消え（R61）、`|`・`;` の被演算子なら i と同じ `(unit _)`（R137）、`#`・`&`・`==`・`!==` の被演算子なら G7。
   - 残った `_` と計算の `!_` は手順4 で読む。
3. 項が1つなら終わる（評価する所なら手順6）。
4. **畳む**：左から1項ずつ畳む。溜まった物は積み上げで、次の項 x はいちばん上の項とだけ結ぶ。
   1. 上が値か空で x が値：積む（構築）。
   2. 上が値か空で x が関数：積む。積まれた関数は後ろの項を右からだけ受け、前の値は取らない（R47）。
   3. 上が口の開いた関数で x が値：適用。x は最初の閉じていない段の口に入る。固定の口が埋まれば段が閉じて結果は次の段へ、全段が閉じれば値。
   4. x が撒く項：流れの1項（R51）。
   5. 上が口の開いた関数で x も関数：合成。x を後ろの段に足し、後から来る物は最初の関数から順に流れ込む（R40）。
   6. 恒等射は単位律で消える（R74・R126）。
   7. 上が種類の未知な値の時と、口の数の分からない関数が受けた後に関数が来た時は、積む予想で通す（R120）。
   8. x が括らない `_`：上が値か空なら口の外の恒等射（R44）。上が口の開いた関数なら R46（口が1つだけ残るなら恒等射として合成、括りの関数なら G5、ほかは G7）。
5. **並びの終わり**：可変長の口（最後の括り・畳む2項の点なし・貪欲な単項・恒等射）と口の数の分からない段は、1つ以上受けていれば閉じる。1つも受けていない段は閉じない。恒等射が流れ1つだけを受けたら、流れのまま次の段へ入る（`i vs~ inc` は `vs~ inc`）。合成の途中の恒等射に流れが来れば、恒等射を消した並びで畳み直す（R126）。
6. **評価する所**（R76）：終わりのいちばん上に口の開いた関数が残れば `(unit …)` で `!_`、恒等射でなければ leftover-lambda（R42・R48）。
   - 既定値の口だけが開いた部分適用は、既定値で埋める（R107）。
   - 返す所に残った裸の関数は `!_` で、bare-function-return（R125）。
   - 評価する所の外でも、値の上に積まれて閉じた関数は `!_`（R52）。`$[…]` の中身は除き、中で余る関数は G20（R59）、何も受けずに閉じた恒等射は消す（R59）。
7. G11 は当たらない。どの対も畳み込みの1歩なので、積み上げはいつも木になる。

- 停止：各項を1回ずつ畳み、終わりで閉じる段は有限なので、項の数に比例する回数で止まる。
- 門にするのは、畳み込みが選びを残す所だけ：口の中の `_`（R46 の G7）・撒いた流れの口（G19）・括りの関数の穴（G5）・R34 が読まない穴（G13）。

### 3.4 できた節の種類

- **素の関数**：仮引数が全部裸の名前で、アリティ n が数えられる関数（名前の定義と `?` の括り）。
- **既定値のある関数**：仮引数のブロックに `名前 : 既定値` の行がある関数。置けるのはファイルの定義と構造体の欄だけ（R134）。n は仮引数の数。
- **k**：実引数の並びの項の数。撒く項は流れの1項。

| 頭 | k | 種類 |
|---|---|---|
| 素の関数（本体の根が A） | k = n | A |
| 素の関数（本体の根が A） | k > n | A。前から n 個の適用の後ろに余りを積む（R35） |
| 素の関数（本体の根が A でない） | k ≥ n | 未知。k > n でも余りは積む予想（R120） |

### 3.7 評価との境

木は変わらない。値の段（value_spec）が読む所：

- 適用の右の構築は、頭のアリティどおりに先頭から取る（R47）。最後の仮引数が括りなら、残りの構築全体を List として受ける（射影）。
- 積んだ構築の値は、書いた構造を保つ。
- 中置の値の演算子に当てた計算の `!_` は、演算子表の Unit の欄が読む。`x + !_` は x。
- 畳む2項の点なしの値は記号ごとに畳む（`^` だけ右から）。`[<]`・`[<=]` は min、`[>]`・`[>=]` は max、`[==]`・`[=]` は全部等しければその値で、違えば `!_`。`!_` はどれでも単位。
- 計算の `!_` と長さ 0 の流れは、置かれた演算の単位（R83）。値の口では消えて口を使わず、既定値のある口では既定値、参照の口では空の器で席を取る（R122）。木の予想は計算の値を知らないので値の段と割れるが、知らせは出さない。
- 既定値の口だけが開いた部分適用は、既定値で埋める（R107。`gq 1` は 2）。
- `_` の値は恒等射（R29）。値の段にはまだ無い（value_spec V12）。
- 行の終わりまで残った足りない関数の値は `!_`（R42）。

## 4. 規則

規則は話題ごとに並べる。番号は前のまま使い、廃止した番号は使い回さない（§4.9）。見出しの % は確信度、括弧は出どころの印。

例の木は HEAD で確かめた物で、HEAD と違う例は「実装は…、§6.4」と書く。知らせは例で見せたい物だけを書き、根に残った関数の leftover-lambda と、値の `$` の dollar-non-function を省いた所がある。知らせが無いことを言う所は「知らせ無し」と書く。行の番号（@n）は、括弧の中の定義を書いた順に1行目から並べ（字下げのブロックで終わる定義の後には空行を1つ置く）、例の行をその後ろに置いて数える。例で定義を書かない名前は、次の定義を使う：

- `inc : x ? x + 1`・`double : x ? x * 2`・`d : x ? x * 10`・`g : x ? x * 10`
- `add : x y ? x + y`・`f2 : x y ? x - y`・`f3 : a b c ? a + b + c`・`use : f x ? @f x`
- `vs : 1 , 2 , 3`・`i : _`・`pw : [a : 1]`・`w : pw ' zz`
- `gq :` ⏎ `⇥⇥x` ⏎ `⇥⇥y : 1` ⏎ `⇥? x + y`（既定値 1 の y を持つ）
- `gd :` ⏎ `⇥⇥ys` ⏎ `⇥⇥zs : 3` ⏎ `⇥? ys + zs`（既定値 3 の zs を持つ）

### 4.1 並びと畳み

#### R1 余積の並びの範囲 — 93%（D・U）

余積の並びは、段11 の空白で隣り合う項のいちばん長い列。段12〜25 は項の中に畳み、段1〜9 は並びを切って、被演算子をそれぞれ別の並びとして畳む（`,` は R19）。括りと囲みの中は、1行ずつ別の並びとして解く。

- `f x + 1 y`（`f : a b ? a * b`、`x : 2`、`y : 3`）→ `(apply f (construct (+ x 1) y))`、値 9
- `inc 1 & inc 2` → `(& (apply inc 1) (apply inc 2))`

#### R2 項は密着で作る — 93%（D・U）

前置・後置の印は、隣の核1つに付く。どの中置（段12〜22）よりも先に結ぶ。前置 `~` も同じで、`~x` は要素1つの List（R79）。

- `f -x`（`f : a ? a`、`x : 3`）→ `(apply f -x)`

#### R8 構築・合成は n 項にまとめる — 93%（R）

構築の子の構築、合成の子の合成は開いて n 項にまとめる。括りと囲みは開かない。

- `inc double inc 5` → `(apply (compose inc double inc) 5)`
- `(inc double) inc 5` → `(apply (compose [inc double] inc) 5)`

#### R11 合成は左から実行する — 96%（U）

`(compose f g)` は f の後に g を実行する。後から来る実引数は、最初の関数から順に流れ込む。

- `double inc 5` → 11、`inc double 5` → 12
- `inc add 5 g 3` → `(apply g (apply add (construct (apply inc 5) 3)))`

#### R19 `,` の辺は辺の中で畳む — 93%（U・D）

`,` の辺の項の並びは、その辺の中で畳む。値だけなら構築のまま辺に残る。辺に関数があっても断らず、左から読む（R121）。

- `1 2 , 3 4` → `(, (construct 1 2) (construct 3 4))`
- `inc 1 , inc 2` → `(, (apply inc 1) (apply inc 2))`、値 `2 3`

#### R35 余りは後ろに積む — 92%（U〔答え〕）

アリティ n の数えられる頭に k > n 個を当てたら、前から n 個を当てた結果の後ろに、余りを値として積む。区間（`[+ 1]`・`[2 *]`）は n = 1。前置・後置の点なしの席（`[-_]`・`[!_]`・`[!!_]`・`[_!]`）は n = 1 に入れず、口は並び全体。

- `inc 3 4` → `(construct (apply inc 3) 4)`、値 `4 4`
- `[+ 1] 1 2 3` → `(construct (apply [+ 1] 1) 2 3)`
- `[!_] 1 2 3 4 5` → `(apply [!_] (construct 1 2 3 4 5))`

#### R40 余積は1つの演算子で、左結合 — 92%（U・U〔答え〕）

並びは左から1項ずつ畳み、次の項はいちばん上とだけ結ぶ。1歩は R47 の3行。

- `5 inc 3` → `(construct 5 (apply inc 3))`、値 `5 4`
- `f2 3 f2 5 6` → `(apply f2 (construct (apply f2 (construct 3 5)) 6))`、値 -8

#### R41 可変長の口は、並びの終わりまで受ける — 92%（U〔答え〕・R）

可変長の口（最後の括り `[~c]`・畳む2項の点なし・貪欲な単項・点なしの席・`||_||`・恒等射）は、並びの終わり（行・括り・値の定義の右辺の終わり）まで受ける。受けている間に来た関数は、合成の後ろに入る。恒等射が受けた後に来た関数は、恒等射を消した並びで畳む（R74）。口の数の分からない関数が受けた後に来た関数は、積む予想（R120）。

- `[+] 1 2 inc 3` → `(apply inc (apply [+] (construct 1 2 3)))`
- `inc [+] 5 6` → `(apply [+] (construct (apply inc 5) 6))`

#### R47 畳みの1歩は3行 — 92%（U・U〔答え〕）

逆適用は無い。畳みの1歩は次の3行だけで、どの対にも1歩があるので、縮めきれない並び（G11）は無い。

1. いちばん上が L で次が A：適用。口を1歩に1つ埋める（前から n 個の後の余りは R35、可変長の口は R41）。全部埋まれば本体の根の種類。
2. いちばん上が L で次が L：合成（後の物は最初の関数から順に流れ込む）。
3. いちばん上が A か空：次を積む（積まれた L は、後ろの項を右から受ける）。

積まれた F の後ろの並び Y は `X (F Y)` と同じで、穴と既定値の規則も F から見る。

- `1 2` → `(construct 1 2)`
- `double inc 5` → `(apply (compose double inc) 5)`、値 11
- `d 1 2` → `(construct (apply d 1) 2)`
- `1 2 inc` → `(construct 1 2 (unit inc))`、leftover-lambda、値 `1 2`
- `5 f2 _ 3` → `(construct 5 (unit (? [$p0] (apply f2 (construct $p0 3)))))`

#### R118 行の値は、書いた並びを左から2つずつ畳んで決める — 92%（U〔答え〕）

2項以上の並びの根の節は、書いた項の並び（written。穴の `_` も書いた位置に）を持つ。`apply`・`construct` の木は、実体と種類のための予想で、値を言わない。予想が割れても断らない。

- `sub (3 < 2) 1 2`（`sub : a b ? a - b`）→ 予想 `(construct (apply sub (construct [3 < 2] 1)) 2)`、値 -1

#### R120 並びは左から読む。種類の決まらない項は値の段が決める — 92%（U〔答え〕）

並びは左から2つずつ畳み、左が関数なら当て、値なら積む。種類の決まらない項（`(gq 1)`・`@$gf`・`use 7 8` など）があっても断らない。値の段が畳むときに決め、木は後ろを積む予想で組む。名前の読みが決まらない項は G7。

- `use 7 8 9` → `(construct (apply use (construct 7 8)) 9)`、未知
- `z 1 2`（`z : @$inc`）→ `(construct z 1 2)`、未知

#### R121 `,` の辺の並びも左から読む — 92%（U〔答え〕）

口が足りた呼び出しは、`,` と空白で同じ。辺の終わりに口の開いた関数が残れば、その辺は関数の因子で、`,` が残れば `!_` になる（R61、leftover-lambda）。最後の口が参照の口なら、`,` の左が括りに入る（R66・R93）。

- `inc 1 , 2` → `(, (apply inc 1) 2)`、値 `2 2`
- `f3 1 , 2 , 3` → `(, (unit (apply f3 1)) (, 2 3))`、leftover-lambda、値 `2 3`

### 4.2 種類と実体

葉の種類は §2、できた節の種類は §3.4 の表のとおり。

#### R24 括りで受けた名前の種類は、呼ぶ側が渡した物の生まれで決まる — 93%（U〔答え〕・R）

括りの関数は、渡された物の形ごとに実体を作る。括りの名前の種類は、渡した物の生まれ（構造体の欄・List の要素。数は長さ1の List。中身の見えない A は未知）。口は受けた List の射影で、最後の括りは残りの並びを丸ごと受ける（R64）。

- `tl 1 2 3`（`tl : [x] y ? x + y`）→ `(construct (apply tl (construct 1 2)) 3)`
- `p3 1 [2 3] 4 5`（`p3 : [a] [b ~bs] [c ~cs] ? a + b + c`）→ `(apply p3 (construct 1 [2 3] 4 5))`
- `f 1 2 3 4`（`f : [a b c] ? a + b + c`）→ `(apply f (construct 1 2 3 4))`、bracket-excess

#### R25 実体の無い本体は読まない — 92%（U）

括りの関数の本体は、呼ばれた形ごとの実体でだけ解く（`(inst 形 本体)`）。呼ばれなければ `(defer …)` のままで断らない。名前の表（name-undefined・同名・隠し）と読む段の文法は、呼ばなくても見る。既定値の中から括りの関数を呼ぶ形は G7。

- `pb : [x] ? x + 1` → `(: pb (? [[x]] (defer {x + 1})))`

#### R26 `'` で引いた物の種類は、引かれた物の生まれで決まる — 91%（R・D）

`x ' k` で x が構造体か List と見え、k が裸の名前（欄の名前）か字面の整数（位置）なら、引いた物の種類はその欄・要素の生まれ（R24）。ほかの鍵・`x @ k`・数から引く形は未知。鍵の名前は名前の表から引かない。

- `p ' a 5`（`p : [a : inc]`）→ `(apply (' p a) 5)`
- `5 ' 0` → `(' 5 0)`、未知

#### R81 素の関数も実引数の印で実体を作る — 92%（U〔答え〕・R）

素の関数の口が全部埋まり、実引数が印（関数の番地・値を読む参照・点と差・`!_` と分かる値）を持てば、印ごとに実体を作り、本体をその印で解く。部分適用と穴の関数も、口が埋まった所で作る。印の無い呼び出しと定義の行は、本体を1回だけ読む。

- `use $inc 5` → `(apply use (construct $inc 5))`
- `sh $vs`（`sh : x ? x + 0x10`）→ G21

#### R136 予想の上の余りは知らせない — 92%（U・R）

関数でありうる項（`@f x`・点なしの答え・既定値の口だけ開いた部分適用・既定値のある仮引数・右辺がそれらの名前）の上に余った関数は、木は `(unit …)` のままで leftover-lambda を出さない。実体が当たれば、当たった方の知らせを1つ出す。関数になりえない答えの上は warning のまま。

- `h : f x ? @f x inc` → `(: h (? [f x] (construct (apply @f x) (unit inc))))`、知らせ無し
- `t 5 inc`（`t : y ? y`）→ `(construct (apply t 5) (unit inc))`、leftover-lambda

### 4.3 `_`（id）

`_` は id。口に置けば穴（その口の恒等射）、口の外では恒等射、点なしでは席。

#### R16 穴は `_` — 92%（U〔答え〕・U）

口を埋める位置の `_` は穴。頭が素の関数か既定値のある関数で、撒く項が無く、`_` でない項が全部 A なら、各 `_` を位置どおりの生成名にした `(? [$p0 …] (apply h …))`（L）。末尾でも、既定値のある口でも穴。k ≠ n は R34。

- `add _ 10` → `(unit (? [$p0] (apply add (construct $p0 10))))`
- `add 3 _` → `(unit (? [$p0] (apply add (construct 3 $p0))))`
- `go _ vs~`（`go : ys ? ys`）→ G13

#### R29 `_` 1つは恒等射 — 92%（U〔答え〕・U・R）

括らない `_` 1つ（行が `_` だけ・`x : _`・口の外）は恒等射で L、並び全体を受ける。単位律で割れる所は、恒等射を消して畳み直す（R126）。`[_]`・`(_)` は R24 で `_`。`[!_]` は否定の点なし。`|`・`;` の被演算子の `_` 1つは `i : _` の i と同じ（R137）。

- `i 1 2 3` → `(apply i (construct 1 2 3))`
- `i inc 1 2` → `(construct (apply inc 1) 2)`
- `1 & _` → G7

#### R34 穴と実引数の数が合わないとき — 92%（U〔答え〕・R）

素の関数（と n の数えられる既定値のある関数）の頭に穴があり k ≠ n のとき：

- k > n：残りを前から穴へ入れ、余りは後ろに積む（`f2 _ 3 4` → `(apply f2 (construct 4 3))`）。
- k < n：穴を前から裸の仮引数にし、書いていない後ろの口を最後の括り `[~c]` 1つで受けて撒く関数（`f3 _ 2` → `(unit (? [$p0 [~$p1]] (apply f3 (construct $p0 2 $p1~))))`）。

撒く項がある k ≠ n は G13、括りの関数の頭は G5。

#### R44 口の外の `_` は恒等射 — 92%（U〔答え〕・R）

括らない `_` が口の外（`_` が来たとき積み上げが空か、いちばん上が値）にあれば、`i : _` の i と同じ恒等射。中置の被演算子の `_` は G7（`,` は R61、`|`・`;` は R137）。

- `_ 5` → `(apply _ 5)`
- `5 _ 3` → `(construct 5 (apply _ 3))`
- `_ + 1` → G7

#### R46 口の中で穴の規則が読まない `_` — 91%（R）

口の中（いちばん上が口の開いた関数）で穴の規則が読まない `_` は、その段が口の数の決まった関数で、口が1つだけ残る所（穴と恒等射が η で同じ関数）だけ通し、恒等射として合成する。口が2つ以上・可変長・口の数の分からない段は G7、括りの関数の口は G5。

- `inc _ inc` → `(unit (compose inc _ inc))`
- `[<<] _ 2` → G7
- `5 io1 _`（`io1 : [say] ? say 21`）→ G5

#### R69 前から n 個の外の `_` は、閉じた後ろの恒等射 — 92%（U〔答え〕）

頭が素の関数か括りの関数（名前の定義か `?` の括り）で、前から n 個に穴が無ければ、その外の `_` は閉じた適用の後ろの恒等射（R44）。既定値のある関数の頭は G13、外の `_` が2つは G7（R46）。

- `inc 5 _` → `(construct (apply inc 5) (unit _))`、値は `inc 5`

#### R74 恒等射は単位律で消える — 92%（U〔答え〕・R）

畳みの1歩で、何も受けていない恒等射（`_`・`i`・括った物・恒等射どうしの合成。並びの頭か値の上）に恒等射でない関数が続けば、単位律で恒等射が消え、木にも書かない。合成の途中の恒等射は木に残す。読みが割れる所（恒等射が受けた後に関数が来る所、恒等射が2項以上を受けて後ろの関数が並び全体を受けない所、撒いた流れが途中に恒等射のある合成に来る所）だけ、恒等射を消した並びで畳み直す（R126）。`||_||` の中の恒等射は消さない。

- `i inc 1 2` → `(construct (apply inc 1) 2)`
- `i 5 inc` → `(construct 5 (unit inc))`、leftover-lambda
- `inc i inc 5` → `(apply (compose inc i inc) 5)`
- `inc i [* 2,] 1 2` → `(apply [* 2,] (apply i (construct (apply inc 1) 2)))`

#### R89 閉じた頭の後ろの口の外の `_` は恒等射 — 92%（R）

頭（素の関数か括りの関数）の前から n 個に穴も撒く項も無く閉じた並びでは、その後ろの口の外の `_` は恒等射（R44）。前から n 個に穴か撒く項がある形と、既定値のある関数の頭は G13。

- `inc 5 _ 6` → `(construct (apply inc 5) (apply _ 6))`
- `pq 1 2 _ 5`（`pq : [a] y ? y`）→ `(construct (apply pq (construct 1 2)) (apply _ 5))`
- `add _ 1 _` → G13

#### R126 木が組める所は、読む段で止めない — 92%（U〔答え〕・R）

書いた形に読みがあって木が組める所は、読む段で止めない。既定値のある関数の実引数の位置・並びの途中の先の分からない `@`・途中の恒等射は、値の段の畳みで決める。恒等射は単位律の側で、恒等射を消した並びで畳み直す。

- `inc i add 5 6` → `inc add 5 6` と同じ `(apply add (construct (apply inc 5) 6))`
- `inc i inc vs~` → `inc inc vs~` と同じ `(apply (compose inc inc) vs~)`（実装は G19、§6.4）

### 4.4 `!_`（void）と評価する所

`!_` は void で、置かれた演算の単位。源の `!_` は計算から生まれた物だけで、手で書いた `!_` は読む段で断る（R138）。

#### R83 計算の `!_` は着いた口の演算の単位 — 92%（U・U〔答え〕）

計算で来た `!_` と長さ 0 の流れは、着いた口の演算の単位。値の口では消えて口を使わない（`f !_ = f`）。既定値のある口（前から数えた位置が既定値のある仮引数）では既定値で、その口に別の値を書いたときと同じ未知の適用。参照の口では空の器 `[]` として席を取り、位置はずれない（本体を読むかは R122）。並びの要素では消える。どれも値の段の規則で、木は変えない。

- `f2 (3 < 2) 1 2` → `(construct (apply f2 (construct [3 < 2] 1)) 2)`、値 -1
- `(add (3 < 2) 1) 5` → 値 6
- `gd 3 (3 < 2) 7` → `(apply gd (construct 3 [3 < 2] 7))`、未知
- `second (3 < 2) 1`（`second : [a] [b] ? b`）→ 値 1

#### R122 参照の口に来た `!_` は空の器 — 92%（U〔答え〕・R）

参照の口に `!_`（計算の物、読む段で `!_` と分かる名前（R91・R115・R102）とその括り、長さ 0 と分かる流れ）が来たら、空の器としてその口で受けて席を取る。頭の名前がある最後の括りと残りを受ける括り（`[a b]`・`[x ~xs]`）は分解が立たないので、本体を読まずに `!_`（木は A）。読む段で分かる物は木の段で、計算の `!_` は値の段でそうなり、木の段では空と分からず本体を読む。`[~xs]` だけの括りと、最後でない括りは本体を読み、空で席を取った括りの名前は全部 `!_`。空の実体は鍵に長さ 0 を足す。

- `seven (3 < 2)`（`seven : [a b c] ? 7`）→ `!_`
- `fq w`（`fq : [a ~r] ? $a == $a`）→ `(apply fq w)`、知らせ無し
- `fq (3 < 2)`（`fq : [a ~r] ? $a == $a`）→ `(apply fq [3 < 2])`、dollar-non-function が2つ
- `fm w 5`（`fm : [a b] [c] ? $a == $a`）→ G7（`$!_ == $!_`）

#### R84 空の流れは `!_` — 92%（U・U〔答え〕）

読む段で長さ 0 と分かる流れ（`!_` と分かる名前（R91・R115・R102）か `!_` と分かる括り（それを括った物と、単位だけの `,` の積 `(w , w)`。R61）に後置 `~` を付けた物）は、`!_` と分かる値と同じで、着いた口で読む。計算の `!_` を撒いた流れは、空と分からず流れの1項。

- `inc w~ 5` → `(apply inc 5)`
- `fz 1 2`（`fz : [a b c] ? inc c~`）→ `(apply fz (construct 1 2))`、bare-function-return
- `g (3 < 2)`（`g : [~t] ? f3 t~`）→ G19

#### R112 値の口の `!_` と分かる名前は消える — 92%（U〔答え〕・R）

読む段で `!_` と分かる名前（R91 の足りない射影・R115 の無い欄・R102 の領域の外を右辺に持つ名前）とそれを括った物は、値の口ではその項を消した綴りと同じ。既定値の口は既定値。参照の口・値の隣・中置では消えない（`,`・`|`・`;` は R137）。

- `inc w 5`（`w : pw ' zz`）→ `(apply inc 5)`
- `w 5` → `(construct w 5)`

#### R115 欄が無い所は `!_` — 92%（R・D）

`'` で構造体を名前で引いて、同じ名前の欄が無ければ `!_`。構造体を括りの名前で受けて欄が無ければ、その名前は `!_`。名前付きスロットに順序は無く、前から当てない。

- `pw ' zz` → 木 `(' pw zz)`、値 `!_`

#### R61 括らない `,` の鎖は1つの積 — 92%（U・U〔答え〕・R）

括らない `,` の鎖は1つの積で、辺（R19・R121 で辺の中を畳んだ物。括りは1つの辺）を因子として、次の順で決める。

1. 単位は先に全部消える。単位は、出どころに依らない `!_`（計算の物・`!_` と分かる名前と括り）と、丸ごと残った恒等射（括らない `_`・`i`・恒等射を括った物）。
2. 残った因子が無ければ空の積で、`,` の単位の `!_`。1つなら `,` は無くなり、その因子が鎖の代わりに鎖の置かれた所に立つ（`(inc , w) 5` は `inc 5`、根の `gq 1 , w` は R107 で埋める）。2つ以上なら `,` が残り、既定値の口だけが開いた部分適用の因子は既定値で埋め（R124）、ほかの口の開いた関数の因子は一斉に `!_`（関数に演算子を直接充てた解なし、R87 と同じ）。

2 で生まれた `!_` は値に残らないが、1 に戻って数え直さない（`(inc , double) 5` は 5）。鎖の値になった `!_`（括った鎖も、`|`・`;` の辺に置いた鎖も）は、鎖の外ではほかの `!_` と同じく置かれた演算の単位（`((inc , double) , double) 5`・`(inc , double | double) 5` は 10）。

木では、恒等射の葉は消して知らせない。単位だけの鎖は `!_` と分かる辺で（R137）、`!_` と分かる辺があればその葉を1つ残す（`w , _`・`w , w` は `w`）。恒等射だけの鎖の葉の綴りは §5 Q100。2 で `!_` になった関数は `(unit …)` で残し、leftover-lambda で `$inc , 2` を案内する。計算の `!_` は値の段で消える。根の `,` が消えて残った並びは行の根で、評価する所。

- `_ , 5` → `5`
- `1 , _ , 2` → `(, 1 2)`
- `w , _` → `w`
- `(3 < 2) , 5` → 木 `(, [3 < 2] 5)`、値 5
- `inc , 2` → `(, (unit inc) 2)`、leftover-lambda、値 2
- `(inc , double) 5` → `(construct [inc , double] 5)`、leftover-lambda、値 5
- `(inc , double , double) 5` → `(construct [inc , double , double] 5)`、leftover-lambda、値 5
- `(inc , (double , double)) 5` → 6
- `(inc , (3 < 2)) 5` → 値 6
- `(_ , _) 5` → `(construct [_ , _] 5)`、値 5（実装は `(apply [_ , _] 5)`、§6.4）
- `_ , _ ; 7` → `7`（実装は G7、§6.4）

#### R137 読む段の木も単位律に揃える — 92%（U〔答え〕・R）

読む段は、綴りで `!_` と分かる辺（無い欄などの名前、評価する所の `(unit …)`、それだけで組んだ `,`・`&`・`|`・`;`・括り）を、`,`・`|`・`;` の被演算子と並置の下で、値の段と同じに単位として消す。並びが `_` 1つの `|`・`;` の被演算子は、名前の `i` と同じ。括らない `,` の鎖の木の中の `(, …)` の節と、R61 の 2 でできた `(unit …)` は、同じ鎖の中では辺でなく、消さない（数え直さない、R61）。

- `w | 5` → `5`
- `_ | 5` → `(| (unit _) 5)`

#### R42 評価する所の終わりに残った未評価のラムダは `!_` — 92%（U・U〔答え〕）

評価する所（`:` の右辺でない行の根と、R76 で広げた所）の終わりに未評価のラムダが残れば `!_`（木は `(unit …)`）。`:` の右辺が丸ごと関数ならラムダのまま残る。

- `inc add 5` → `(unit (apply (compose inc add) 5))`、leftover-lambda、値 `!_`
- `c1 5`（`c1 : inc inc`）→ 値 7

#### R48 評価する所で余ったラムダは `!_` で、知らせる — 92%（U〔答え〕・R）

評価する所で余ったラムダは `!_` になって並びの中で消え、warning の leftover-lambda で知らせる（断らない）。余ったのが恒等射か、下が関数でありうる項（R136）なら知らせない。

- `5 inc` → `(construct 5 (unit inc))`、leftover-lambda、値 5
- `5 i i` → 知らせ無し

#### R52 値の上に積まれて何も受けずに閉じた関数は `!_` — 92%（U〔答え〕）

`$[…]` の中を除くどの並び（括りの中・`:` の右辺・辺・本体の行・枝の条件と値・囲み）でも、値の上に積まれた関数が並びの閉じるまでに何も受けなければ `!_` になって消え、leftover-lambda で知らせる。

- `(5 inc) 3` → `(construct [5 inc] 3)`、値 `5 3`
- `v 3`（`v : 5 inc`）→ `(construct v 3)`、値 `5 3`

#### R76 評価する所は、根・比べと論理の被演算子・手続きの行 — 92%（U〔答え〕・R）

評価する所は、行の根・比べと論理（`;`・`|`・`&`・`==`・`!==`）の被演算子・手続き（`:` の行の無い2行以上の字下げの本体）の各行（最後の行も）。本体の返す所（1行の本体の根・1行の字下げの本体・枝の値）は入れない（R125）。手続きの `_` だけの行は G7。

- `inc == 5` → `(== (unit inc) 5)`、leftover-lambda
- `pp 1`（`pp : x ?` ⏎ `⇥x` ⏎ `⇥inc`）→ `(apply pp 1)`、leftover-lambda

#### R87 値の演算子の被演算子は評価する所 — 92%（U〔答え〕・U）

値の演算子（段12〜16・19〜22）の被演算子と、値の印（前置 `-`・`!!`・後置 `!`）の核は評価する所で、丸ごと残った関数は `!_`（leftover-lambda）。`!f` は未知。括らない値の印の核の `_` は名前の id と同じで、解なしの `!_`（知らせない）。中置の被演算子の `_` は G7。

- `inc + 1` → `(+ (unit inc) 1)`、値 1
- `-_ 5` → `(construct -_ 5)`、値 5
- `!inc 5` → `(construct !inc 5)`、未知

#### R116 `#` の右は評価する所 — 92%（U〔答え〕）

中置 `#` の右の被演算子（書き込む値）は評価する所。裸の関数は `!_` になり、leftover-lambda で `$inc` を案内する。左に当たる演算が無ければ、値の段で `!_`。`p # _` は G7。

- `p # inc`（`box : 0`、`p : $box`）→ `(# p (unit inc))`、leftover-lambda

#### R107 既定値の口だけが開いた部分適用は、評価する所で既定値で埋める — 92%（U〔答え〕・R）

評価する所で、いちばん上の既定値のある関数が1つ以上受け、開いた口が全部既定値の口なら、既定値で埋める。木は開いた口に既定値の印 `!_` を置く。関数のまま残すなら `_` の穴を書く。何も受けていない関数は埋めない。

- `gq 1` → `(apply gq (construct 1 !_))`、未知
- `gq 1 _` → `(unit (? [$p0] (apply gq (construct 1 $p0))))`

#### R124 器の要素の部分適用も既定値で埋める — 92%（U〔答え〕・R）

括りの中の2項以上の並び（器の要素）と、`,` が残る鎖の因子（R61）に置いた、既定値の口だけが開いた部分適用も、既定値で埋める（R107）。中が1項の括り・名前の右辺・単位が消えて1つだけ残った `,` の因子は関数のまま。埋めるのは値の段。

- `[3 (gq 1)]` → `[3 2]`
- `[gq 1] 5` → 6
- `(gq 1 , w) 5` → `(construct [gq 1 , w] 5)`、未知、値 6

#### R125 本体の返す所に残った裸の関数は `!_` — 92%（U〔答え〕・U）

`?` の本体の返す所（1行の本体の根・1行の字下げの本体・枝の値）に裸の関数（種類 L か区間）が残れば、その関数は `!_` を返す。断らず、information の bare-function-return で知らせ、`$` での持ち上げを案内する。恒等射は知らせない。`$` で持ち上げた関数と、本体で呼んだ結果は当たらない。返す所に残った、1つ以上受けて開いた口が全部既定値の口の部分適用は、既定値で埋める（R107。`t : y ? gq y` の `t 1` は 2）。

- `k 1 5`（`k : x ? inc`）→ `(construct (apply k 1) 5)`、bare-function-return、値 5
- `adder 5`（`adder : m ? [+ m]`）→ bare-function-return。関数を返すなら `$[+ m]` と書く。
- `pq 1`（`pq : x ?` ⏎ `⇥inc`）→ `(apply pq 1)`、bare-function-return

### 4.5 点なしと囲み

#### R31 畳む2項の点なし — 92%（U・U〔答え〕・R）

両側の欠けた畳む中置（算術・`||`・`;;`・`&&`・`|`・`&`・`;`）の `[op] x1 … xn` は、結合の向きどおりに並べた中置と同じ。比べの点なしは積（`[<]` は min、`[>]` は max、`[==]` は全部等しければ左）で、`!_` は単位。1項は、数か全部 A の List なら A、ほかは未知。

- `[-] 10 3 2` → `(apply [-] (construct 10 3 2))`、値 5
- `[<] 1 (5 / 0) 3` → 値 1
- `[+] 5 g 3` → `(apply g (apply [+] (construct 5 3)))`。`[+ 5] g 3` と同じく、`[+]` が先に当たり g は後。

#### R32 畳まない2項の点なしは、素の2引数の関数と同じ — 92%（U〔答え〕）

畳まない2項の点なし（`<<`・`>>`・`'`・`@`・範囲・`!=`・`!==`・中置 `#`）は、素の2引数の関数と同じに読む（k = 2 は適用、k = 1 は部分適用、k > 2 は余りを積む）。値の演算は A、get・set は未知。information の pointfree-not-folded で知らせる。`[<<] _ 2` は G7。

- `[<<] 1 4 2` → `(construct (apply [<<] (construct 1 4)) 2)`、pointfree-not-folded

#### R50 `[F,]` の写像 — 92%（U〔答え〕・U）

`[F,]` は、F が要素1つに当てて閉じる関数（口が1つ残った関数か、前に固定の口の無い可変長の口だけの関数・恒等射）なら要素ごとの写像で、`[F,] a b` は `F a , F b`。全部 A なら A。F の口が2つ以上か分からない、または固定の口の後ろに可変長の口があれば未知。

- `[inc,] 1 2 3` → `(apply [inc,] (construct 1 2 3))`
- `[add,] vs` → `(construct [add,] vs)`、未知

#### R77 段18 の点なしは口1つ — 92%（U〔答え〕）

段18 の片側の欠けた点なし（`[' k]`・`[@ k]`）は口1つで、1つ受ければ閉じ、余りは後ろに積む。撒いた流れは書き下しで、合成全体の口は1。引いた物の種類が決まらなくても、未知で畳む。

- `[' 0] [1 2] 5` → `(construct (apply [' 0] [1 2]) 5)`
- `[' 0] [1 2 3] inc 4` → `(construct (apply [' 0] [1 2 3]) (apply inc 4))`

#### R95 点なしの可変長の口に来た長さ 0 の流れ — 92%（U〔答え〕）

点なしの可変長の口（`[* 2,]`・`[inc,]`・席の点なし・恒等射、それを頭にした合成）が長さ 0 と分かる流れを1つ受けたら、何も受けていないのと同じで、点なしの関数が残る。畳む2項の点なし（`[+]`）とそれを頭にした合成は、R31 の1項で A。

- `fe 1 2`（`fe : [a b c] ? [* 2,] c~`）→ bare-function-return
- `[+] w~` → `(apply [+] w~)`、A
- `[+] inc w~` → `(apply (compose [+] inc) w~)`、A

#### R27 囲みの中の関数 — 91%（U・U〔答え〕）

`|f|`・`||f||`（中が1行で根が関数）は、関数に値の演算子を直接当てた解なしで `!_`（R87・R61 と同じ、leftover-lambda）。`||_||` はノルムの口の穴で、並び全体を数える（`[~x] ? ||x||`）。中が値なら A。`|_|` は未知。

- `||_|| 1 2 inc` → `(apply inc (apply ||_|| (construct 1 2)))`
- `|inc| 5` → `(construct |inc| 5)`、leftover-lambda、値 5（実装は知らせない未知、§6.4）
- 実装はまだ `||f||` を合成で読む（`||inc|| 1 2` → `(construct (apply ||inc|| 1) 2)`。§6.4）。

### 4.6 括りと流れ

#### R64 括りの名前は射影 — 92%（U〔答え〕・U）

最後の括りの仮引数（参照の口）は、行の残りを1つの List で受け、名前は前からの射影。足りない名前は `!_`（R91）、余りは受けず、書いた時点で多いと分かれば information の bracket-excess。撒いた流れ1つだけなら、撒いた器そのものを受ける。

- `f 1 2 3 4`（`f : [a b c] ? a`）→ `(apply f (construct 1 2 3 4))`、bracket-excess
- `f vs~`（`f : [a b c] ? a`）→ `(apply f vs~)`

#### R91 射影が `!_` と分かる名前は、木の段でも `!_` — 92%（U〔答え〕）

括りの関数の素直な括りの仮引数に、書いた時点で長さの分かる List（書き並べ・字面・`,` の積・撒いた流れ1つ。数は長さ1）が名前より短く来たら、足りない後ろの名前は木の段でも `!_`。実体はその長さで分ける。残りを受ける名前（`~xs`）は長さを持たない。

- `fe 1 2`（`fe : [a b c] ? $c == $c`）→ G7（`$!_ == $!_`）

#### R66 最後の口が参照の口なら、`F … x , R` は `F … (x , R)` — 92%（U〔答え〕）

`,` のすぐ左の項（の並び、R93）が括りの関数 F の最後の括りに入るなら、`F … x , R` は `F … (x , R)`：積で List を組んで参照の口に渡す。値の口だけの関数は、R121 で `,` の辺を左から畳む。

- `f 1 , 2 , 3`（`f : [a b c] ? a`）→ `(apply f [1 , 2 , 3])`
- `pb 1 , 2`（`pb : [a] [b] ? a`）→ `(, (unit (apply pb 1)) 2)`、leftover-lambda

#### R93 書いた形がそのまま実引数の形 — 92%（U〔答え〕）

R66 の x は `,` のすぐ左の項の並びで、書いた形がそのまま実引数の形になる（`fp 1 2 , 3` は `[[1 2] 3]`）。受けられるかは括りの形が決める。

- `fp 1 2 , 3`（`fp : [a b c] ? a`）→ `(apply fp [1 2 , 3])`

#### R51 撒いた流れは1つの項 — 92%（U・U〔答え〕）

撒いた流れ `xs~` は畳みの1歩で1つの項になり、いちばん最初の閉じていない段に入って、受ける関数全体の残りの口の数で受ける。合成なら、受ける段の口に、後ろの段ごとに口 − 1 を足した数（名前や括りで包んだ合成も同じ）。後ろの段の恒等射は、単位律で消してから数える（R126。`||_||` の中は消さない）。口が2つなら左からの畳み込み、1つなら書き下し（頭を当て、残りは後ろに積む）、最後の可変長の口なら丸ごと。3つ以上・分からない・畳まない2項の点なしは G19。

- `add vs~` → `(apply add vs~)`、値 6
- `inc vs~` → `(apply inc vs~)`、値 `(inc 1) 2 3`
- `inc add vs~` → `(apply (compose inc add) vs~)`、値 8
- `f3 vs~` → G19
- `inc f3 vs~` → G19
- `inc i add vs~` → `inc add vs~` と同じ `(apply (compose inc add) vs~)`（実装は G19、§6.4）
- `inc i f3 vs~` → `inc f3 vs~` と同じ G19

#### R79 前置 `~` は単一の対象を要素1つの List に持ち上げる — 92%（U〔答え〕）

前置 `~` は単一の対象か括りの式にだけ係り、`~x` は書いた `[x]` と同じ項。`~$x` は `[$x]`。`~!_` と `~[]` は読む段で断る。`~_` は `~i` と同じく `[_]` の恒等射（R138）。

- `~1 2 3` → `(construct ~1 2 3)`
- `inc ~_ 5` → `inc ~i 5` と同じ `(apply (compose inc ~_) 5)`（実装は `(construct (apply inc ~_) 5)`、§6.4）

#### R67 仮引数の裸の `~xs` は断る — 93%（U）

括りの外に前置 `~` を付けた仮引数（`a ~y`・`~y`・`[a] ~y`・仮引数のブロックの `~y` の行。既定値と組んだ `~y : 3` も）は、定義の所で G22。呼ばれない定義でも断り、言い分で `[x ~xs]` と括る道を案内する。

- `gx : a ~y ? a` → G22

### 4.7 `$`・`@`・番地

#### R99 `$` はいつも持ち上げ — 92%（U・U〔答え〕）

`$` はいつも持ち上げで、先の種類では断らない（下ろすのは `@` と `' i`）。先が関数なら関数の番地、関数でない物（値の名前・値の括り・字面・番地）は値を読み書きする参照（印 vref、R100 で知らせる）、種類が書いた所で分からない物は印 lift（`$?`）。値を読む参照は `@` で指す値を読み、`#` で書ける。値の演算子の被演算子では番地の点（R62）。G20 に残るのは、後置の印（R57）・中で余る関数（R59）・書いた `,` の積（R101）・括りの中の名前（R54）。

- `$inc` → `$inc`、知らせ無し
- `$[5 inc]` → G20

#### R100 `$` が関数以外を持ち上げたら知らせる — 92%（U・U〔答え〕）

`$` の先が関数でない物（値の名前・仮引数で受けた値・字面・器・`,` の積の名前・足りた適用・非同期の手形など）なら、通して warning の dollar-non-function で知らせる。関数・零射（`!_` と分かる名前）・種類の分からない先は知らせない。知らせは書いた `$` の項ごとに1回で、括りの関数の実体で決める。

- `$vs` → dollar-non-function
- `$_` → 知らせ無し

#### R101 書いた `,` の積の `$` は断る — 92%（U・U〔答え〕）

`$[…]`・`$(…)` の中身が書いた `,` の積で、単位律（`_`・`i`・`!_` と分かる辺が消える）を当てても `,` が残れば G20。1項に縮めば、その項の `$`。単位だけで0項に縮めば `!_` と分かる括りで、零射の番地（R56）。名前を通して初めて積と分かる物は R100 の知らせ。

- `$[v , 1]`（`v : 1`）→ G20
- `$[inc , _]` → `$inc` と同じ
- `$pq9`（`pq9 : 5 , 99`）→ dollar-non-function

#### R49 番地は指す物の印を運ぶ — 92%（U〔答え〕・U・R）

`$名前`・`$[…]` で関数を物にした番地は指す関数の印を持ち、`!_` と分かる値（R91・R115・R102 の名前とそれを括った物）は印 zero を持つ。印は名前を引いた種類から付け、右辺が関数の別名（`p : inc`・合成・部分適用）の `$p` も指す関数の印を持つ。恒等射の `$_`・`$i`・`$[i]` の印は1引数の `[x ? x]`（§5 Q98）。印は `:`・括り1つ・実体の仮引数（括りの関数の欄・要素・裸の仮引数と、R81 の素の関数）へ持ち越し、実体の鍵に入る。`@x` の x に関数の印があれば、`@x` はその関数そのもの（口の数が分かる）。実体の中の zero の `$s` は零射の番地（R56）。

- `map $inc vs`（`map : f [~l] ? [@f,] l~`）→ `(apply map (construct $inc vs))`
- `map $p vs`（`map : f [~l] ? [@f,] l~`、`p : inc`）→ `(apply map (construct $p vs))`
- `h [s : w]`（`h : [s] ? $s`）→ 知らせ無し
- `h [s : 5]`（`h : [s] ? $s`）→ dollar-non-function

#### R56 `$` の先の `!_` と分かる物は零射の番地 — 92%（U・U〔答え〕・R）

`$` の先が `!_` と分かる名前（R91・R115・R102）か、それに後置 `~` を1つ付けた長さ 0 の流れ（`!_~ = !_`）か、それを1行で括った物なら、零射 `$[x ? !_]` の番地（A、指す関数の印を持ち、知らせない）。R57 の G20 には当たらない。`$[!_]`・`$(!_)` は否定の点なしの番地。

- `$w`（`w : pw ' zz`）→ `$w`、知らせ無し
- `$w~` → `$w~`、知らせ無し
- `$[w]` → `$[w]`、知らせ無し

#### R57 `$` と後置の印の組み合わせ — 92%（U・U〔答え〕・R）

後置の印（`~`・`!`・`@`）の付いた `$` の項（中身がそれ1つの括りも同じ）は、どちらが先に結ぶ読みでも割れるので G20。長さ 0 と分かる流れの `$w~` は割れず、R56 の零射の番地。後置の印が無ければ `$` の先は残り全部で、関数なら印のある番地（`$||_||`・印のある `$@f`）。

- `$inc~` → G20

#### R59 `$` の先のどこかで余る関数があれば G20 — 92%（U・U〔答え〕・R）

`$[…]` の中身のどこか（入れ子の括り・囲み・欄の右辺・`?` の本体）か、`$名前` の先（右辺・本体。括りの関数の本体は、`$` で物にして呼んだ実体で見る）に、値の上に積まれて口が開いたまま閉じた関数があれば G20 で、`$inc`・`$[…]` と書く道を案内する。値の上に余った恒等射は書いた所で消す（知らせない）。`$` を通さずに呼ぶ所は R52 の知らせで通る。

- `$[add (5 inc)]` → G20
- `$[add (5 _)]` → `$[add [5 _]]`
- `$[5 _]` → `$5` と同じ、dollar-non-function
- `use $bq 5`（`bq : [x] ? x inc`）→ G20
- `bq 5`（`bq : [x] ? x inc`）→ `(apply bq 5)`、leftover-lambda

#### R54 括りの中の名前の `$` は断る — 92%（U・U〔答え〕）

関数の本体の字下げの `:` の行は枝（R128）なので、`$名前` は本体の行を見ない。括りと構造体のブロックの中の名前を `$` で指すと、どの定義を指すか決まらないので G20（local-field）。`$[N]`・`$(N)` は `$N` と同じ先。

- `[sq : z ? z * z` ⏎ `$sq]` → G20

#### R102 `$x ' 0` は x — 92%（U〔答え〕・R）

中置 `'` の左が `$` の持ち上げ（`$x`・それを運ぶ名前・括り1つ・仮引数）で鍵が字面の整数 k なら、k = 0 は下ろした x（`@[$x]` と同じ）、k ≠ 0 は領域の外で `!_`。名前・式の鍵、番地の算術の点、先の分からない持ち上げには当てない。

- `($inc ' 0) 5` → `(apply [$inc ' 0] 5)`

#### R78 先の分かる前置 `@` は位置に依らない — 92%（U〔答え〕・R）

`$` の印で先の分かる `@x`（関数の番地・値を読む参照・`!_` と分かる名前。印は名前の右辺からも持ち越す、R49）は、並びのどこでも先そのもの（関数なら関数、値なら値）として読む。ずらした点・差を指す `@x` は G21。先の分からない `@x`（印の無い値の名前も）は種類の未知な項として畳む。

- `5 @[$inc] 3` → `(construct 5 (apply @[$inc] 3))`
- `inc @[$inc] 5` → `(apply (compose inc @[$inc]) 5)`
- `5 @p 3`（`p : $inc`）→ `(construct 5 (apply @p 3))`

#### R103 持ち上げだけを通る輪は通し、下ろす所を通る輪は断る — 92%（U・U〔答え〕）

`$` は中身を評価しないので、輪が持ち上げ（`$v`・`$[…]` の中身）を通るだけなら通す（v は A、指す値は中身の見えない A）。定義の時に下ろす所（持ち上げの外の `@`・`' i`。関数の返値や名前を通して下ろす所も）を通る輪は name-cycle。輪の中の書いた積・撒いた形は、輪の外と同じ G20。

- `v : 1 , $[v + 1]` → 通る
- `v`（`v : f9 1`、`f9 : x ? x , $v`）→ `v`、dollar-non-function
- `v`（`v : f9 1`、`f9 : x ? @[$v]`）→ name-cycle
- `v : 1 , ($v ' 0)` → name-cycle

#### R62 番地の点と差 — 92%（U〔答え〕・R）

番地の点 P（`$` の値の参照、点に置いた `0x…`）と差 D（P − P と、点と組む `+`・`-` の被演算子の `0x…`。その名前・括り1つ・`0x… ± 0x…` も）は Address で、数と混ぜない。通すのは顔が1つに決まる組だけ：P ± D と D + P は P、P − P と D ± D は D、比べは点どうし・差どうし・点と `0x…`。どの層でも書ける。P + P・D − P・点と差の比べ・差と `0x…` の比べ・番地と数の混ぜ・顔の分からない値との組は G21、関数を指す番地を値の演算子か比べに置けば G7。番地の顔の無い中置（`0x10 + 1`・`0x10 + 0x20`）は A。

- `$vs + 0x10` → `(+ $vs 0x10)`
- `$vs - $vs` → `(- $vs $vs)`、差
- `($b - $a) + $vs`（`a : 1`、`b : 2`）→ `(+ [$b - $a] $vs)`、点
- `$vs + (0x10 + 0x8)` → 点
- `$vs == 0x10` → `(== $vs 0x10)`
- `$vs + $vs` → G21
- `0x1000 - $vs` → G21
- `($vs - $five) == $vs`（`five : 5`）→ G21
- `$inc + 1` → G7

#### R97 幅の倍数でない差を点に足し引きする形は断る — 92%（U〔答え〕・R）

点 ± 差で、点の要素の幅が木の段で分かり（Int とその List、幅 8 byte）、差の値が書いた時点で決まっていて、差が幅の倍数でなければ G21。倍数かは字面の最大公約数で見る。

- `$vs + 0x3` → G21
- `$vs + 0x8` → `(+ $vs 0x8)`

#### R98 `差 / 数` は数 — 92%（U〔答え〕・R）

`差 / 数` は数（割る数は Int と書いた所から分かる物に限る）で、層に依らない。答えは数と足せて、点とは混ぜない。割る数が Int と分からない形・`差 % 数`・`差 * 数`・`差 / 差`・`点 / 数` は G21。

- `($b - $a) / 8`（`a : 1`、`b : 2`）→ `(/ [$b - $a] 8)`、数
- `($b - $a) / 1.5`（`a : 1`、`b : 2`）→ G21

### 4.8 読む段・名前・本体

#### R138 `_` は id、`!_` は void — 92%（U・U〔答え〕）

`_` は id（恒等射・穴・点なしの席）、`!_` は void（置かれた演算の単位）。読む段は次の3つを断る：手で書いた `!_`（void-written。点なしの席 `[!_]` は否定の点なしで通す）、書いた空の器（empty-written。`[]`・中身が詰まって空になる括り・`[]~`）、見える範囲に定義の無い名前（name-undefined、R21）。括らない値の印の核の `_` と `~` の核の `_` は名前の id `i` と同じ：`-_` は R87、`~_` は `~i` と同じ `[_]` の恒等射（R79）、`_~` は `i~` と同じ G7（中身に関数の見える器を撒く形、§5 Q20）。ほかの位置の `_`（`_ + 1`・枝の条件）は G7。

- `!_ 1 2` → void-written @1
- `inc _~` → `inc i~` と同じ G7（実装は `(apply inc _~)`、§6.4）
- `[!_] 1 2 3 4 5` → `(apply [!_] (construct 1 2 3 4 5))`（席の口は並び全体）

#### R21 未定義の名前は断る — 91%（U）

書いた所から見える範囲に定義の無い名前は、読む段で断る（name-undefined）。呼ばない本体・解かない所でも断る。取り込みのある範囲の名前は未知（G7、§5 Q10）。`'` の右の鍵は名前の表の外。

- `say 5` → name-undefined
- `hh : [x] ? zz` → name-undefined（呼ばない本体でも）
- `io@` ⏎ `say 5` → G7

#### R22 決まらない形は名指しで断る — 92%（U〔答え〕・U）

読みが1つに決まらない形は、黙って `!_` にせず門で名指しして断る（§6.2）。木が組めて値の段で決まる所は値の段に任せる（R119・R120・R126）ので、当たるのは残った門と読む段の断り。

- `_ == 1` → G7
- `f [1]`（`f : [x ~xs] ? f [xs xs]`）→ G7（実体の形が深くなり続ける）

#### R119 読みは2段 — 92%（U〔答え〕・U）

読む段は、文法に無い形が1行でもあればファイルごと止めて行を名指す。値の段は、木が組めて当たる演算が無い所を `!_` にして知らせ、走らせる。比べの連鎖は、向きの揃った3項の範囲と、`=` だけ・`==` だけの連鎖を通し、ほかは compare-chain。

- `0 <= 3 < 5` → `(< (<= 0 3) 5)`、値 3
- `1 != 2 != 3` → compare-chain @1
- `(+ 1 2)` → infix-missing-operand @1

#### R127 断りと知らせは、元のソースの行を持つ — 92%（U・U〔答え〕）

読む段の断りと値の段の知らせは元のソースの行（1 から）を持ち、どの段でも書いた行を指す。同じ源で2つ以上当たれば先の段で断る：前処理 → 文法 → void-written・empty-written → 外の同名 → 仮引数 → 使う所の `#` → name-undefined → 解く段。言い分に行は書かない。輪は名指す定義の行、量の上限はいちばん外の行を指す。

- `p [(inc 5) (inc 5)]`（`inc : x ? x + 1`、`p : [x ~xs] ? q x`、`q : [y] ? $y == $y`）→ G21 @3（q の本体を書いた行）
- `a : 1` ⏎ `a : !_` → void-written @2（外の同名より先）

#### R117 続きの行は、行頭に空白のある行だけ — 95%（U・U〔答え〕）

前処理で、行頭（改行か TAB の後）に空白がある行だけが前の行の続き。深さ 0 の空行は越えない（括りとブロックの中の空行は読み捨てる）。コメントの行の後の続きの行・`?` の行・ブロックは断る。

- `width : 640` ⏎ `␠+ 16` → `(: width (+ 640 16))`
- `width : 640` ⏎ `+ 16` → infix-missing-operand @2
- `width : 640` ⏎ 空行 ⏎ `␠+ 16` → 構文の断り

#### R128 関数の本体の字下げの `:` の行は枝 — 92%（U〔答え〕・R）

関数の本体の字下げのブロック（枝の値のブロックも）の `:` の行は、左が何であっても枝で、本体に局所の定義は無い。枝の条件は `&` の左と同じ式として解き（1項も）、条件に残った関数は `!_`。枝の値は返す所。枝のある本体の値は `(c1 & v1) | … | 既定の行` と同じで、値が `!_` の枝（無い欄・足りない射影・領域の外の名前・計算の `!_`・返す所の裸の関数）は書かなかったのと同じで次の枝へ進み、全部消えたら `!_`。括り `[…]` の中の行と、ファイルの `名前 :` のブロック（構造体）の行は欄。

- `h 3`（`inc : x ? x + 1`、`h : x ?` ⏎ `⇥inc : 1` ⏎ `⇥x`）→ 3、leftover-lambda @3
- `bb 5`（`bb : x ?` ⏎ `⇥x : 1` ⏎ `⇥2`）→ 1
- `f 3`（`f : x ?` ⏎ `⇥x > 0 : 1 / 0` ⏎ `⇥7`）→ 7
- `f 0`（`f : m ?` ⏎ `⇥m > 0 : 1` ⏎ `⇥m < 0 : 2`）→ `!_`
- `pr : x ?` ⏎ `⇥y : x + 1` ⏎ `⇥y * 2` → name-undefined @2

#### R130 枝のある本体の裸の行は、最後の1行だけ — 92%（U・U〔答え〕）

枝の行が1つでもある本体（と枝の値のブロック）では、裸の行は最後の1行（既定の行）にだけ置ける。それ以外の裸の行があれば読む段でファイルごと止め、最初の裸の行を名指す（body-bare-row-between）。枝の無いブロックは手続き（R76）。

- `f : x ?` ⏎ `⇥x > 0 : 1` ⏎ `⇥x` ⏎ `⇥x < 0 : 2` ⏎ `⇥0` → body-bare-row-between @3
- `f : x ?` ⏎ `⇥x > 0 : 1` ⏎ `⇥x` ⏎ `⇥0` → body-bare-row-between @3

#### R131 仮引数の括りに既定値は書けない — 92%（U〔答え〕・U）

仮引数の括り（`[…]`・`(…)`）は参照の口で、既定値を持たない。括りの中のどこか（入れ子も）に `:` の行があるか、仮引数のブロックの行の左が括りなら、読む段でファイルごと止め、その行を名指す（param-default-bracket）。既定値は字下げの仮引数のブロックの `名前 : 既定値` の行に書く。

- `gq : x [y : 1] ? x + y` → param-default-bracket @1
- `f :` ⏎ `⇥⇥[y] : 1` ⏎ `⇥? y` → param-default-bracket @2

#### R133 仮引数の隠しは内側が勝つ — 92%（U〔答え〕・R）

仮引数がファイルの定義か外の関数の仮引数と同じ名前なら、その関数の中では仮引数が隠す。断らず、information の name-shadow を隠す名前ごとに出す（近い方を名指す）。同じ範囲の同じ名前は name-duplicate で断る。既定値の右に見えるのは前の仮引数まで。

- `h 2`（`inc : x ? x + 1`、`h : inc ? inc 5`）→ `(apply h 2)`、name-shadow @2、値 `2 5`
- `a : 1` ⏎ `f : a a ? a` → name-duplicate @2

#### R134 字下げの仮引数のブロックは、名前の定義の綴り — 92%（U〔答え〕・R）

字下げの仮引数のブロックで書いた関数は、名前の定義（ファイルのいちばん外と構造体の欄）にだけ置ける。枝の値・既定値の値に置いたら、既定値の行の有無に依らず読む段でファイルごと止め、そのブロックを持つ `:` の行を名指す（param-block-position）。

- `f : c ?` ⏎ `⇥c :` ⏎ `⇥⇥⇥y : 1` ⏎ `⇥⇥? y` ⏎ `⇥0` → param-block-position @2
- `obj :` ⏎ `⇥m :` ⏎ `⇥⇥⇥y : 2` ⏎ `⇥⇥? y` → `(: obj (block (: m (block (? [{y : 2}] y)))))`

#### R135 括りの中に `?` の行は置けない — 92%（U〔答え〕・U）

複数行の括り（`[`・`(`・`{`）の中で `?` から始まる行は、TAB に依らず前処理でファイルごと止め、その `?` の行を名指す（param-block-bracket）。言い分は置き場ごとに書き直し先を出し分けるだけで、断る・通すには使わない。名前の無い関数は1行の括りで書く。

- `[` ⏎ `⇥⇥x` ⏎ `⇥? x + 1` ⏎ `] 5` → param-block-bracket @3
- `g : [` ⏎ `⇥⇥x` ⏎ `⇥⇥y` ⏎ `]` ⏎ `⇥? x + y` → 通る（参照の口の関数）

### 6.1 閉じているか

- 91% 以上の規則は、90% 以下の所に頼らずに書ける。
- 木の形が割れる所は、全部「未知」か門（§6.2）に落とした。
- 「未知」は、根でも隣と結ぶ時でも断らない。木は畳みの予想で、値は値の段が書いた項の並びを畳んで決める。断るのは、名前の読みが決まらない項と、中身に関数か未知の見える器を撒く・写す・貪欲な単項で受ける形だけ（G7）。

### 6.3 試験の見本

木と値の見本は alpha1/javascript/test/coproduct.test.js にある。仕様には写さない。

### 6.4 実装で気を付けること

1. 種類を計算する順：定義を集め（P2）、名前の種類を決め、素の関数の本体の根を決めて（再帰は仮置きと解き直し）、各並びを解く。括りの関数の本体は、実体を作る時だけ解く。
2. 門の時機：前検査で G7 の器（中身に関数か未知の見える器を撒く形。`$` の番地を並べた `fs~` は通る、§5 Q20）と名前。`_` の段で G13。畳み込みの1歩で G5 と G7。流れの段で G19。`$` の項で G20。中置の項で G21・G7。
3. `,` を解く所で、被演算子の恒等射を消す。根の `,` が消えて並びだけが残った行は、評価する所として包み直す。
4. 関数の項は、書いた関数を段に開いて持つ。段の口の形（固定の口の数・可変長・不明）は、関数の種類から1か所で決める。
5. 評価する所の外でも、積み上げが2項以上でいちばん上が口の開いた関数なら `(unit …)` で包む（R52）。`$[…]` の中身は包まない。構築の中の `(unit …)` は、形・desc・要素・数から除く。
6. 穴とカリー化は並び全体の前処理で見つける。括りの中の行も、行全体で見る。穴の節は対に入らない（括りに入れば L の葉）。R34 の k > n で埋めた形は、ふつうの適用。
7. `_` と `!_` を真偽として読まない。`_` は id、`!_` は void。
8. 試験は、木の試験と値の試験を分ける。値の試験は値の段が決まってから入れる。断られる見本は「今は断る」試験として置き、答えが出たら通る側へ移す。

**仕様と今の実装の違い**

- `|f|`・`||f||`：仕様は解なしの `!_`（R27）。実装は `||f||` を合成で読み（`||inc|| 1 2` → `(construct (apply ||inc|| 1) 2)`）、`|f|` を知らせない未知の葉にする（`|inc| 5` は `(construct |inc| 5)` の未知）。
- infix-mixed-assoc（同じ段で結合の向きが違う中置が続く形）・definition-end-blank-line（字下げのブロックで終わる定義の後に空行が無い）と、前段・P1 の front-end-shape・operator-unknown・operator-removed：実装は断るが、この仕様に規則が無い。
- G18（coproduct-identity-row）：名前だけ実装の表に残り、当たらない。
- `~` の核の `_`（R79・R138）：実装は `~_`・`_~` を名前の id と読まずに未知の葉にする（`inc ~_ 5` は `(construct (apply inc ~_) 5)`、`inc _~` は `(apply inc _~)`、`x : _~` は通る）。仕様は `~i`・`i~` と同じ。
- 括らない `,` の鎖（R61）：実装は、恒等射だけの鎖（`_ , _`・`i , i`・`(i) , [_]`）を空の積と読まずに恒等射の葉を1つ残し、恒等射の関数として読む。そのため、残った `_` が `|`・`;`・`&`・`==`・`!==`・`#` の被演算子・手続きの行・枝の条件・撒く形に来ると G7 で断り（`_ , _ ; 7`）、括りと名前は恒等射として適用・合成する（`(_ , _) 5` は `(apply [_ , _] 5)`、`i , i ; 7` は未知、`$[_ , _]` は恒等射の番地）。仕様は `w , w` と同じ `!_` と分かる辺。
- 値の段は、関数だけが3つ以上残る鎖を、括りの中・定義の右辺・`|`・`;` の辺・手続きの行で interpret-not-yet で止める（`(inc , double , double) 5`）。根と裸の返す所の鎖は `!_` で通る。
- 撒いた流れが合成の途中の恒等射に来る形（`inc i inc vs~`）：仕様は恒等射を消して読む（R126）。実装は後ろの段の恒等射の口を数えられず、G19 で断る。
- 言い分の中に、使わなくなった番号（R28・R33・R39・R45・R53・R58・R70・R75・R94・R96・R105・R108・R123・R129）を引く所がある。今の答えは §4.9 の表から引ける。
- 値の段にまだ無い物（`_` の値・値の演算子の `!` ほか）は、value_spec V12 にある。

### 6.5 90% 以下の所の扱い

§5.1 の各行の「今は」が、実装での扱い。
