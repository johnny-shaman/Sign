## 0. 前置き

### 0.1 位置づけ

- 値で種類が変わる所は、解決器の門や個別の問いで閉じない。値の段で動かして型を付け、利用者の書くテストと合わせて最終の型を導き、テストに出てこない枝は AOT で止めて危険を明示する。
  - U [2026-11-03 21:47 159479c9]「…値の段に任せて、とりあえず動作を作る。 / すると、それで型が付く。 / その型を使ってユーザーが書くテストも合わせて最終的な型を導く。 / テストに出てこない枝は、AOTコンパイルでは停止して危険を明示していい。」
- 文面 V1〜V12 は、主の Claude が見せた文面に U〔答え〕[2026-11-03 22:42:49 159479c9]「入って」（問い「直した文面で解釈器の片1に入っていい？」、ボタンの名と同じ語）。
- 線は「90% を超えて確かな所だけ実装する」。超えない所は V12 の「まだ」で、行を名指しして止める。

## 1. 規則

### V1 入口
- **文面**
  - 先に `resolve` を通す。読む段の断りはファイルごと止める（R119）。
  - 値は、書いた行の木（`resolve` の `rows`）の項の並びを、左から2つずつ畳んで決める（R118）。
  - 解決器の木と種類は予想で、値を決めない。試験が値と突き合わせるだけに使う。
  - `resolve` に足すのは、書いた行の木 `rows` と、行の木から元のソースの行を引く `lineOf` だけ。
- **出どころ**：R118・R119。U 2026-11-04（§0.1）。

### V2 値
- **文面**
  - 値は次の4つ。
    - Int（64 bit。BigInt で持つ）
    - `!_`（void）
    - 並び（2つ以上の値。1つの並びは値そのもの、`[x] ≅ x`。ただし x が点なしの席（`[-_]` など）の時は、印を id の後に当てた合成（仕様 R35。口の数え方は R27 の `||_||` と同じ）。口を並び全体に数える点なしの記法で、括り1つではない、V5）
    - 関数（仮引数が全部裸の名前の関数と、その部分適用・合成）。id `_` も関数の値（評価は V12 のまだ）
- **出どころ**：U〔答え〕[2026-10-28 00:0x 438d5b1a]（Int は 64 bit）。`[x] ≅ x` は bialgebra の読み（メモリ）。

### V3 畳みの1歩
- **文面**
  - いちばん上が関数で次が値なら適用、次も関数なら合成（左の関数から実行する）、ほかは積む。
  - 口が埋まった関数の答えは、合成の次の段へ流し、段が尽きた後の答えは並びに積む。
  - 余った実引数は後ろに積む。
  - 値の口に来た計算の `!_` は消える。いちばん上が値のときに来た `!_` も消える（並びの単位）。書いた `!_` は読む段が断る（R138）。R91・R115・R102 の名前の `!_` も同じ読みのはずだが、その名前の値は器の片・解2 の後（今はまだ、V12）。
  - 未定義の名前は読む段が断る（R138）。取り込みのある範囲の表に無い名前は、まだ（V12、仕様 §5 Q10）。
- **出どころ**：R11・R35・R40・R47・R120（解決器の予想と同じ規則）。
  - 値の口の `!_`：R83・R112、U〔答え〕[2026-10-27 15:5x 58a809c9]「…書いた・名前・計算の _ は値の口でどれも同じ。…」（前の綴りで、`_` は今の `!_`。書いた `!_` と未定義の名前は読む段が断る、R138・R21）。
  - 未定義の名前：R21・R138。

### V4 評価する所
- **文面**
  - 評価する所では、余った関数は `!_`。評価する所は次の所。
    - 行の根
    - 演算子の被演算子（`,` は下の単位律が先。`|`・`;` は V7）
    - 手続きの行
    - 枝の条件と値
    - 本体の返す所
  - 定義の右辺と括りの中は評価する所ではない。並びに1つだけ残った関数は関数のまま、値の上に残った関数は `!_`。
  - `,` の辺も左から畳む。括らない `,` の鎖は1つの平らな積で、辺（因子）を関数のまま読み、次の順で決める。
    1. `!_` の辺は、出どころ（計算・0 除算・`!_` を返す呼び出し）に依らず積の単位で消える。恒等射の辺も単位（仕様 R61。値の段の恒等射は V12 のまだ）。
    2. 残った辺が1つなら `,` は無くなり、その辺が鎖の代わりに鎖の置かれた所に立つ（仕様 R61。関数の辺は、括りの中・定義の右辺なら関数、根・本体の返す所なら `!_`。既定値の口だけが開いた部分適用は、根・返す所で既定値で埋める、R107・R125）。`(inc , (3 < 2)) 5`・`(inc , (1 / 0)) 5`・`((3 < 2) , inc) 5`・`(f3 1 , (3 < 2)) 2 3` は 6（読む段は leftover-lambda の予想、仕様 §5 Q95）。
    3. 2つ以上残れば `,` が残るので、辺に丸ごと残った関数は一斉に `!_`（R61）。この `!_` は値に残らないが、1 に戻って数え直さない（`,` は残ったまま）。`(inc , double) 5` は 5、`(inc , double , double) 5` も 5、`(inc , 3) 5` は `3 5`、`(inc , (double , double)) 5` は 6、`((inc , double) , double) 5` は 10。
       - 辺を読んで空なら単位とする順にすると、`(inc , double) 5` が 6 になって R61 の 2 が壊れる（辺そのものが関数なら単位の一覧に入らない）。
       - 単位で `,` が消えて1つ残った辺は 2 のとおり行の置かれた所のままで、R124 の埋めは当たらない（`(gq 1 , w) 5` は `(gq 1) 5` と同じ 6、仕様 §5 Q97。w は R115 の `!_` と分かる名前）。既定値は解2 の片。
    4. `,` は段を保つ。3 の後にも `,` が残り、辺が2つ以上の値なら、その辺は1つの要素（`1 2 , 3 4` は行が2つの2次元で、`[1 2] , [3 4]` と同じ）なので器の片（V12）。辺がどれも1つの値（`1 , 2 , 3`）なら1次元で、片1 で持つ。`,` が単位で消えた形（`1 2 , (3 < 2)`）と、3 の `!_` のほかに辺が1つしか残らない形（`1 2 , inc`）は `1 2`（R）。
- **出どころ**：R42・R52・R76・R87・R125（関数の `!_`）。R61・R121（`,`）。
  - `,` の単位律：U [2026-11-04 04:26:26 a75d0a52]「空白が積に解決される時と同じなんだけどなぁ。 / ,は空白での積を明示することで、2次元配列とかを作る時の用途を想定しているんだよね。」（主の Claude の問い [03:07:20]「`,` の辺の `_` は、出どころに関わらずどっちに揃える？」への打った言葉で、数は言っていない。6 は R）。承認した V4 の元の文面は「`,` は左から畳み、`_` は単位（R61・R121）。」（U〔答え〕[2026-11-03 22:42:49 159479c9]「入って」）で、書いた `_` に限っていなかった。R61 の 2 の解なしも値に残らない：U〔答え〕[2026-11-04 06:04:34 a75d0a52]「消える」（問いは `|` と `&` の解なしの物。`,` へ広げたのは主の Claude の [06:00:47] の文に基づく R）。読む順（関数のまま → 単位律 → R61 の 2）は R。引用と元の文面は前の綴りで、`_` は void。
  - 平らな積（3 の一斉の `!_` と、数え直さない所）：主の Claude の問い「括らない `,` の鎖は、1つの平らな積として数える（Q89 は 5）でいい？」に U〔答え〕[2026-11-12 f79a80f9]「1. 平らな積」。Q97・Q99 は、単位律が先（U 2026-11-04 04:26）と平らな積からの1歩（R）。
  - 段を保つ：U [2026-09-20 04:28:19 b29e2269]、U [2026-09-23 08:58:04 590370b4]「これは式の通りに二次元から一次元に落としてほしい」、R93 の U〔答え〕2026-10-26 23:39、U 2026-11-04 04:26。

### V5 算術
- **文面**
  - `+ - * / % ^` は Int の上の演算。`!_` は両側の単位（`(3 < 2) - 2` は 2）。
  - `/` は 0 へ切り捨て、`%` はその余り。
  - 0 で割る・溢れ・負の指数の冪は `!_`。
  - 前置 `-` は符号を変える（`-(1 / 0)` は `!_`。`-(3 < 2)` は 10-30 の算術の線の外で、今はまだ）。当てるのは、芯の中の演算子が算術の範囲の時だけ。渡された仮引数は見ない（`neg : a ? -a` ⏎ `neg (5 > 3)` は -5）。
    - 片1 で通す芯は、字面・`_`（id で、下の線の外の答え）・仮引数と、それを算術の中置でつないだ物、それを1つ括った物（未定義の名前は R138 で断る。算術の中置でつないだ物の中の計算の `!_` は `-(1 / 0)` のとおり）。
    - 線の外の芯の答えは `!_` と information（U〔答え〕10-30 17:58）だが、読む段がまだ線を引かないので、線の外と言い切れない芯（定義の名前・適用・比べ）は V12 のまだで止める。
    - 括りの中が値の印（前置 `-`・`!!`、後置 `!`）か否定の `!` の1つと `_` だけの1行（`[-_]`・`(-_)`・`[!_]`・`[!!_]`・`[_!]`。2行に割った `[` ⏎ `-_` ⏎ `]` も）は点なしの席で、口を並び全体に数える点なしの記法（仕様 R27・R35、§2・§3.5）。括り1つ（`[x] ≅ x`、V2）ではなく、片1 では V12 のまだ。
    - 括らない `-_`・`!!_`・`_!`（重ねた `-_!` も）は、id に値の印を当てた形。`_` が識別子の id として当たり（仕様 R138）、`-i` と同じく関数に演算子を直接充てた解なしで `!_`（仕様 R87）。芯が id そのもの（括った `(_)` も）なら関数と言い切れるので、線の外の答えの `!_` を返し、恒等射なので知らせない（R48 の線。線の外の芯の information は、恒等射でない芯に出す）。`!!`・後置 `!` も同じ（`!!_ 5`・`_! 5` は 5）。`-_ 5` は 5、`[-_ 5] 3` は `5 3`。名前を通した `-i`（`i : _`）は定義の名前の芯で、V12 のまだ。
    - 芯を括った `-(_)`・`[-(_)]` は、括った id に `-` を当てた物で、点なしではない（`-(_) 5`・`[-(_)] 5` は 5。R）。
- **出どころ**：U〔答え〕[2026-10-28 00:0x 438d5b1a]「…Int の割り算は 0 へ切り捨て、0 で割ると Int・UInt は _、…Int の溢れは _、…負の指数の冪と負の階乗は _、Int は 64 bit。」（前の綴りで、`_` は今の `!_`）。
  - 両側の単位と単項の印：U〔答え〕[2026-10-28 00:17:32 438d5b1a]「それでいい。算術とビットの2項は _ が両側で単位（_ - 2 は 2、3 / _ は 3）、単項の -_・!!_・_! は _、||_|| は 0、|_| は _。」（問いとボタンの文は主の Claude の物）。前の綴りで、`_` は今の `!_`（void に印を当てた形と void の囲みの答え）。単項の値は同じ `!_` で、括らない `-_` は id に印を当てた解なし（R87）。計算の void の囲みは `||(3 < 2)||` が 0、`|(3 < 2)|` が `!_`（絶対値・ノルムは V12 のまだなので、入れる時の答え）。
  - 前置 `-` の線：U [2026-10-30 14:47]「…中の演算子が算術の範囲になっている場合は、前置-を許容する」、U〔答え〕14:52「通す」（渡された仮引数）。
  - `[-_]` は点なし：U [2026-10-30 14:55:34 70d14389]「…なお、 [-_] は 点無しで関数となる。 / / 計算として、-_ がそのまま評価されたら、そりゃ解なし _ だね。」。綴りは U [2026-10-21 08:20:37 cfb4de1d]「これがよさそうだね。 / その方が統一的に扱えると思う。」（主の Claude の、前の `_` の綴りに戻す案への返事）。U〔答え〕10-30 14:59:50「それでいい」は主の Claude の傾きの表への答え。`-(_)`・`[-(_)]` を点なしに数えないのは R。14:55:34 は、席の `-_` を括らずに評価したら解なし、という言葉で、理由も今の読みと同じ（`_` は前の綴りの void で、今の `!_`）。
  - 括らない値の印の識別子の id：U [2026-11-09 13:18:07 2617ea04]「-_ は括らないとポイントフリーとして認識できない。」「他方で括らないというなら、識別子が当たるよね。」（仕様 R138）。
- 溢れの `!_` はその場で生まれて単位で消える（alpha1 の `(MAX+2)+(0-2)` は -2。U 2026-10-27 23:43・U〔答え〕23:51）。

### V6 比べ
- **文面**
  - 中置の `<`・`<=`・`>`・`>=` は、成り立てば左、外れたら `!_`。0/1 の例外は無い。
  - どちらかが `!_` なら `!_`。
  - 括らない3項の範囲（読む段が通すのは向きの揃った3項で、`<` と `<=`、`>` と `>=` は混ぜてもいい。仕様 R119）は、成り立てば真ん中、外れたら `!_`（`0 <= 0 < 5` は 0、`0 <= 5 < 5` は `!_`）。
  - `==` は深く比べて、等しければ左。どちらかが `!_` なら `!_`。並びの比べは器の片（V12）。
  - Int の `=` は `==` と同じ値。並び・番地・文字の `=` は V12。
  - `=` だけ・`==` だけの連鎖（何項でも。仕様 R119）は、全部等しければ一番左、どこかが違えば `!_`（`1 == 1 == 1` は 1、`2 == 3 == 3` は `!_`）。木は左の背骨で、左から畳むとこの値になる。`!_` が混ざれば `!_`（`1 == (3 < 2) == 1`）。
- **出どころ**
  - 成り立てば左：U [2026-10-27 23:01 438d5b1a]、U〔答え〕[23:5x]「…比べは成り立てばいつも左（0 < 5 は 0）。…」。
  - `!_` と外れた範囲：U [2026-11-03 22:42 159479c9]「x < _ や _ < x は 全部 _ / 外れた範囲も _」（前の綴りで、`_` は void）。
  - 連鎖：U [2026-10-27 23:33・23:34 438d5b1a]、U〔答え〕[23:36]。範囲と `=`・`==` の連鎖：U [2026-11-05 15:52 de332d62]「比較演算の種類が同じなら通せる。/ 不等号、以上、以下の連鎖は3項までで、範囲を示すため。/ = と == は、何連鎖でも行けるよね。」、U〔答え〕[15:55]「範囲なら通す」。Int の `=` を `==` と同じ値にしたのと、`!_` の混ざった連鎖を `!_` にしたのは R（Int の上の2つの等しさは同じ点を選ぶ。`!_` は中置の片側の `!_` の1歩）。
  - `==`：U〔答え〕2026-10-27 23:54。`==` の片側の `!_` は R（「全部 _」を `==` にも読んだ。引用は前の綴り）。
  - 点なしの比べは中置とは別の射（仕様 R31）：`[<]`・`[>]` は min・max（積そのもの）で、`!_` は単位。`1 < (3 < 2)` は `!_` で、`[<] 1 (5 / 0) 3` は 1（2項なら `[<] a b` は `(a < b) | b | a` と同じ値）。値の段に入れるのは解2（V12）。

### V7 論理
- **文面**
  - `&` は左が `!_` なら右を読まずに `!_`、ほかは右（右に丸ごと残った関数は `!_`、V4）。
  - `|`・`;` の辺は関数のまま読み、`!_` の辺は出どころ（V4 の一覧。`&` の解なしも）に依らず両側の単位として先に消える。消えた辺は演算子ごと無くなり、残った辺は行の置かれた所のまま（括りの中・定義の右辺なら関数、評価する所なら `!_`）。
  - 消えた後にも `|`・`;` が残れば、被演算子に丸ごと残った関数は `!_`（R76）で、それも単位で消える。
    - `|`：左が `!_` でない値なら右を読まずに左。左が丸ごとの関数なら右を読み、右が `!_` なら左の関数、右が `!_` でない値なら右、右も丸ごとの関数なら `!_`。
    - `;`：両側を読み、片方だけが値ならその値、両方とも値か両方とも `!_` なら `!_`（`inc ; 3` は 3、`inc ; double` と `3 ; 4` は `!_`）。
  - 例：`((3 < 2) | inc) 5`・`(inc | (3 < 2)) 5`・`(inc ; (1 / 0)) 5` は 6。`(c & inc | double) 5` は c に依らず 10。`(inc | double) 5`・`(inc ; double) 5` は 5、`(inc | 3) 5` は `3 5`。
  - `|`・`;` は2項ずつ左から結ぶ（木の左の背骨）ので、`(inc | double | double) 5`・`(inc ; double ; double) 5` は 10。括らない `,` の鎖は1つの積で数え直さない（V4 の 3、`(inc , double , double) 5` は 5）のとは別の演算。
  - ほかの演算子は両側を読む。
  - `&`・`|`・`;` は値を見ずに `!_` かどうかだけを見るので、並びもそのまま通す。並びを見る値の演算子（算術・比べ・`==`・前置 `-`）に並びを当てる形は器の片（V12）。
- **出どころ**：U〔答え〕2026-10-27 23:38（短絡）、U 2026-10-27 23:56（`;`）。U [2026-10-29 12:52 32fe4b9c]「_ ; 5 = _ 5 = 5 _ = 5 ; _ / さらに、 / _ | 5 = _ 5 = 5 _ = 5 | _」（前の綴りで、`_` は void）。
  - 関数の辺：U〔答え〕[2026-11-04 05:34:28 a75d0a52]「6 に揃える」（問い「`(_ | inc) 5` と `(inc ; _) 5` の答えはどっち？」とボタンの文は主の Claude の物）、U〔答え〕[2026-11-04 06:04:34 a75d0a52]「消える」（問い「`c & inc | double` の `c & inc` の解なしも、`|` の単位として消える？」は主の Claude の物）、R61 の 2 は U [2026-10-30 17:55:42 bba373f5]。左右・名前と計算の `!_`・定義の右辺へ広げたのは U〔答え〕[2026-10-29 12:56:39 32fe4b9c]「合ってる」（問い「気づいてほしかったのは、この読みで合ってる？」と、12:53:56 の主の Claude の読み「値が書いた `_` でも、名前に束ねた `_` でも、計算で来た `_` でも同じ」への答え）から1歩（R）。引用と問いの例は前の綴りで、`_` は void（今の `!_`）。鎖を2項ずつ左から読むのは R。

### V8 本体
- **文面**
  - 本体は1行か、字下げのブロック。
  - ブロックに枝（`:` の行）が無ければ手続き `l1 & … & ln`。`!_` の行で止まり、最後の行の値を返す。
  - 枝が有れば選び。`(c1 & v1) | … | 既定` と同じ答えで、値が `!_` の枝は次の枝へ進む。既定の行は最後に1つだけ置ける。
  - `:` の行は、左が名前1つでも枝（本体に局所の定義は無い）。条件は `&` の左と同じに読むので、計算で `!_` になる条件の枝は通らない（`pr : x ?` ⏎ `⇥x < 0 : 1` ⏎ `⇥x * 2` の `pr 3` は 6）。未定義の名前の条件は読む段が断る（R138）。枝の下の字下げのブロックも同じ規則。
  - 枝の前か間に置いた裸の行と、2つ以上の既定の行は、読む段がファイルごと止める（`body-bare-row-between`）。
  - 末尾は最後の枝と既定の行だけ。最後でない枝の値は `c & v | 次の行` の v なので末尾でない（V10）。
- **出どころ**：R76（手続き）。U〔答え〕2026-10-29 12:46、U [2026-10-29 12:52 32fe4b9c] と U〔答え〕「合ってる」（枝の値の `!_` は次へ進む）。U〔答え〕2026-10-29 12:18「ガイドに戻す」（左が名前1つでも枝）・戻7（混ざった本体はファイルごと止める）・U〔答え〕2026-11-01 問8「それでいい」（枝の値は末尾でない）。仕様 R128・R130。

### V9 定義
- **文面**
  - ファイルのいちばん外の定義は順序に依らない（使う行が定義の前でもよい）。同じ名前の2つ目は読む段が断る（`name-duplicate`）。右辺に書いた `!_`・書いた空の器を置いた定義は、読む段が断る（R138）。右辺が `_` の定義は恒等射の名前（`x : _` ⏎ `x : 5` は name-duplicate）。
  - 定義は自分の行で1回走らせて覚える。先に引かれたら、その時に1回走る。だから引かれない定義も走り、その中の「まだ」は止まり、知らせも出る。
  - 深さの上限（V10）で欠けた値は覚えない。後で引かれたら走り直す（覚えると、後の行の値が前の行の深さで変わる）。
  - 定義でない行の値はファイルでは捨てる。試験の口（`interpret` の `values`）は行ごとに返す。
  - 名前は内から引く：関数の中では、その関数の仮引数、外の関数の仮引数、ファイルの定義の順。仮引数がファイルの定義や外の仮引数と同じ名前なら、関数の中ではいつも仮引数（隠しは読む段の知らせ `name-shadow` で、値の段には何も足さない）。既定値の行の右に見えるのは、その関数の前の仮引数まで（読む段の規則。既定値の値は V12 のまだ）。
    - `inc : x ? x + 1` ⏎ `h : inc ? inc 5` ⏎ `h 2` は `2 5`。`x : 5` ⏎ `g : x ? x + 1` ⏎ `g 2` ⏎ `x + 1` は `3 | 6`（外の行の x はファイルの x）。
    - 関数自身の名前を仮引数にすると、本体のその名前は仮引数で、再帰にならない（`f : f ?` ⏎ `⇥f == 0 : 0` ⏎ `⇥f (f - 1)` の `f 3` は `3 2`）。
- **出どころ**：U〔答え〕2026-10-31「引かれた時」（自分の行で1回、先に引かれたらその時に1回）。順序に依らない：2026-09-19 の決着（メモリ）。U〔答え〕2026-10-30 15:23（行の値を捨てる）。名前は内から引く：U〔答え〕[2026-10-29 12:12:33 32fe4b9c]「内側が勝つ」、仕様 R133。既定値の範囲はガイドの "preceding parameters"（R133 の R の所）。

### V11 知らせ
- **文面**
  - 次の所で `!_` が生まれたら、生まれた行に information を出す。同じ理由と行の組は1回だけ。

    | 理由 | 所 |
    |---|---|
    | `zero-division` | 0 で割った |
    | `int-overflow` | Int（64 bit）の溢れ |
    | `no-operation` | 当たる演算が無い（負の指数の冪） |
    | `resource-depth` | 入れ子の深さの上限 |

  - 関数が `!_` になる所は、読む段の知らせ（`leftover-lambda`・`bare-function-return`）のままで、値の段では足さない。
    - 読む段は関数でありうる項の上の余り（`h : f x ? @f x inc` の定義の行）を予想の上では知らせず（仕様 R136）、実体が当たった方だけを出す（`h $inc 5` は leftover-lambda、`h $add 5` は bare-function-return）。実体を作らない呼び出し（印の無い値を渡す `k 5 5`）は、読む段は何も言わない（値の段は h の本体の前置 `@` が V12 の「まだ」で止まる、interpret-not-yet）。値の段が当たった理由を出すかは解2。
    - 値の段は `!_` を出どころに依らず `,`・`|`・`;` の単位で消す。読む段も、綴りで `!_` と分かる辺（R91・R115・R102 の名前とそれを括った物・評価する所で `!_` になった丸ごとの関数（`(unit …)`）・それだけで組んだ辺）を同じ所で消す（仕様 R137、§5 Q91）。計算で `!_` になる辺（`(3 < 2)`・`1 / 0`・`!_` を返す呼び出し）は読む段には分からないので、隣の関数に予想の leftover-lambda が残り、値（`(inc , (3 < 2)) 5` は 6）と割れる。値の段が当たった理由を出すかは解2（仕様 §5 Q95）。
