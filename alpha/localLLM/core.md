# Sign の核

Sign を書くのに要るものだけを並べる。他の言語の常識は持ち込まない。予約語は無い。

## 書き方の単位

- 定義は `名前 : 式`。関数は `名前 : 仮引数 ? 本体`。本体は字下げ（TAB）のブロックに書ける。
- 適用は空白：`f x y`。関数どうしを並べると合成になる。
- 定義されていない名前はすべて `__` になる。`null`・`false`・`if`・ループの構文は無い。
- 行頭の `` `…` `` だけの行は注（コメント）。

## `__`（Unit）

`__` は零対象で、対象として見れば値（空の器）、射として見れば関数（素通り）。単位律かつ単位元である。

- 吸収する：`f __` は `__`（完全性公理：関数に `__` が来たら呼び出しごと潰れる）、`__ & x`、比較。
- 単位元になる：`__ | x` は `x`、`__ + 3` は `3`、空白（並べる）と `,` でも消える。
- 偽は `__`。比較は成り立てば左辺を返し（`3 < 5` は `3`）、成り立たなければ `__`。
- `a & b`：`a` が `__` なら `__`（`b` は評価しない）、そうでなければ `b`。
- `a | b`：`a` が `__` でなければ `a`、そうなら `b`。
- `a ; b`：片方だけが `__` でなければその値、両方なら `__`（排他的）。
- `!x`：`x` が `__` でなければ `__`。

## 分岐：match_case

`?` の後のブロックの各行は `条件 : 値`。上から見て最初に成り立った行の値を返す。条件の無い最後の行が既定。

```sign
fact : n ?
	n < 2 : 1
	n * (fact (n - 1))
fact 5
```

`&`・`|` だけでも分岐は書ける（`xs == __ & y | z`）。

## 仮引数の形（渡し方は型ではなく形で決まる）

| 形 | 受け取るもの |
|---|---|
| `x` | 値 |
| `[~x]` | 器（List・String・Struct）を参照で1つ |
| `[h ~t]` | 器の頭 `h` と残り `t`（残りも器。尽きたら `__`） |
| `[foo ~this]` | 構造体から `foo` を取り、器そのものを `this` に |
| `x ~xs` | ストリーム（カッコ無し。同時に複数の位置は持てない） |
| `$f` を渡し `@f x` で呼ぶ | 関数（`$` で番地にして渡し、`@` で呼ぶ） |

ローカル変数は無い。要るときは**既定値つきの仮引数**で書く（状態ベクタ。呼ぶ側から上書きもできる）：

```sign
f :
		x
		y : x + 1
	? x + y
f 3
```

## 器

- 空白で並べると List：`1 2 3`。文字列は文字の List：`` `abc` ``。文字は `\a`。`,` は直積（構造体）。
- 構造体はブロックの行で書く：
  ```sign
  p :
  	a : 1
  	b : 2
  ```
- 引く：`l ' 0`（先頭）、`l ' -1`（末尾）、`p ' b`（名前）、`p ' k~`（`k` の中身を名前として）。
- 鍵の `~`：`l ' 1~` は切り出し（1番目から後ろ、器のまま）、`l ' i~` は `i` の中身で1つ引く、
  `l ' i~~` は `i` の中身の位置から後ろ。
- `||l||` は要素数。`l~` は中身を撒く（`f l~` は要素を別々の実引数として渡す）。
- 分解した残りを並べ直すときも `~` が要る：`f : [h ~t] ? (h + 2) (f t)~`。
- 範囲：`[1 ~ 5]` は `1 2 3 4 5`、`[1 ~+ 2 ~ 9]` は `1 3 5 7 9`。

## 繰り返し

- 再帰（末尾再帰は平らになる）。`[h ~t]` で分解すれば、尽きたところで完全性公理が止める。
- 写像 `[* 2,] [1 2 3]~` は `[2 4 6]`、選択 `[< 3,] 1 2 3 4` は `[1 2]`、畳み込み `[+] 1 2 3 4` は `10`。

## 実世界

- `@addr` は読む、`addr # v` は書く（成功すれば番地を返す）、`$x` は番地を取る。
- 取り込み：`` `file.sn`@~ ``。
