### Lean の基礎についての断り

- Lean と Mathlib は選択公理を含む。
  - だから、Lean で通った証明が言うのは「選択公理を使ってよい数学で正しい」ことだけ。
  - 「選択なしで成り立つ」を Lean で確かめられるのは、`#print axioms` に `Classical.choice` が出ない証明だけ。
  - Mathlib の補題は選択を使う物が多いので、F の節と I の節の大半、J の `Typing.lean`・`Arith.lean`・`Digits.lean` は Mathlib を使わずに書いた。
- ZF + AD は選択公理と矛盾する。だから、決定性の公理の側の主張は Lean では扱えない（§5 の未決へ）。

## 2. 定義

### 2.1 中心の定義（〔R〕。ここは利用者に確かめたい）

**二つの側とつなぎ**は、次の3つの組。

1. 空間の側 S：デカルト閉で、有限の余積を持つ圏（だから分配圏）。
   - ランベック圏の側で、Lawvere の不動点定理が働く。
2. 量の側 Q：零対象と二項の双積を持つ圏（Lawvere 1992 の線形圏）。
3. つなぎ F : S → Q：有限の余積を保つ関手（Lawvere 1992 p.19 の「外延量の型」）。

この組について：

- 1 と 2 を1つの圏に詰めると自明になる（B.1・B.2）。
- 分けてつなげば壊れない（A.1〜A.5 の模型）。
- 付点集合の圏 Set* は、S = Set から Q = CMon への途中の段 X ↦ X₊ ↦ ℕ^(X) に居る。

## 3. 定理

### A. 二つの側の模型（`TwoSides.lean`）

| # | 主張 | 印 | 証明の筋 |
|---|---|---|---|
| A.1 | Set（`Type`）は零対象を持たない。 | 〔L〕 | 空集合は終対象でない。 |
| A.2 | CMon では1点のモノイドが零対象。 | 〔L〕 | 準同型は 0 へも 0 からも1本だけ。 |
| A.3 | CMon では A × B が inl・inr で余積、fst・snd で積になる（双積）。 | 〔L〕 | 余積の普遍性は (a, b) ↦ f(a) + g(b)。 |
| A.4 | つなぎ ℕ^(−) : Set → CMon はすべての余積を保つ。 | 〔L〕 | 忘却関手の左随伴（Mathlib の `AddCommMonCat.adj`）。 |
| A.5 | CMon は自明でない（ℕ は零対象でない）。 | 〔L〕 | ℕ → ℕ の恒等と零が違う。 |

Set はデカルト閉（Mathlib の `MonoidalClosed (Type u)`）。A.1〜A.5 で、2.1 の組に自明でない模型があることになる。

### E. Lawvere の不動点定理と嘘つきの文（`Lawvere.lean`）

| # | 主張 | 印 | 証明の筋 |
|---|---|---|---|
| E.1（Lawvere） | 積を持つ圏で Φ : A×A → B が弱く点全射なら、B のどの自己射にも不動点がある。 | 〔L〕 | g = f∘Φ∘⟨id, id⟩ を表す点 a を取ると、s = Φ(a, a) が f の不動点。 |

〔R〕利用者の「この手紙は嘘である」の読み：

- 前置 `!` は射でなく（D.4・D.5）、名前の付いた否定も、行の段で零射に潰れる（J.22(c)）。Set* の射には、不動点の無い物が無い。
- でも、式の中の `e ; v` は不動点の無い写像を書く（J.22(a)(b)）。だから、嘘つきの文の材料は言語に在る。
- Sign が違うのは、自己参照の答えの置き場。同じ実引数の必ず読む輪は読む段の断り（問10。枝の中なら眠る、問12）に、実引数の変わる輪は行の `!_`（11-19 の決め）に置く。どちらもまだ入っていない。今の alpha1 は、前者を interpret-not-yet で止め、後者では打ち切りの深さの偶奇で作り話をする（J.23）。

#### I-5. この節が利用者の主張について言うこと（〔R〕）

「評価しきったか」には、2つの意味がある。

- **関数が残ったか**（leftover）：行の畳みは有限なので、いつも決まる（仕様 194 行：項の数に比例する回数で止まる）。I.1 の振り分けに LPO は要らない。
- **返らない計算も含める**：振り分けに WLPO・LPO が要る（I.13）。Sign は打ち切りを行の `!_` にして、この線の手前に留まる（I.14。11-19 の決めで、仕様・実装はまだ）。

`f !_ = !_` と振り分けは、既存の数学で書ける。

- この節の定理は、どれも Lean で通った。証明は既存の道具（Set* ≃ Par の制限圏、歪ブール代数、smash の閉構造、構成的逆数学）の中で済む。だから「既存の数学では証明できない」とは言えない。
- 言えるのは、次の4つの不可能性。どれも「標準の構造1つでは持てない」の精密な形。
  1. 零対象を持つ閉な構造1つに、口の段（`f !_ = f`）と行の段（`f !_ = !_`）を同居させられない（I.2(a)、B.1・B.6）。2つは Set* の2つの積（× と ∧）に分かれる。
  2. `|`・`;` は Set* の全部の射について自然でない（I.7(a)）。配れるのは、値か `!_` かが入力に依らない射だけ（I.8）。
  3. 零対象と積を持つ圏の、単位つきの自然な演算は可換で、左優先の catch になれない（I.9）。
  4. 拾う `!_` を発散と同じ点にすると、catch は単調でない（I.10）。

Sign は、この4つの壁の間を通っていると読める。

- 値の空間を X₊ に保つ（`!_` を見える値にする）ので、振り分けに公理が要らない（I.11(d)）。
- 真偽の専用の値は作らず、真偽は射 {`_`, `!_`} の側に住む（I.3）。
- 証人を返す述語は、X → 2 と情報を失わずに1対1（I.4(c)）。

選択公理と決定性の公理について：

- I.11(c) が中身を持つのは、直観主義の土台（IZF・トポス・Lean の型理論）の上だけ。
- 古典の ZF には排中律が入っているので、AC を足しても AD を足しても、振り分けは全部在る。
- AC と AD で動くのは、η の側（G・§5）。

- 「決まる」「決まらない」は数の段の数学の主張で、右の列が Sign の今。
- 列の行は構成的な基礎での論理の強さ、計算できる実数の行は算法の有無で、違う尺度。
- 実代数的数は、囲む区間を決まった二分で選べば正規形になる。等しさが決まるのに、正規形は要らない。
- 名前の比べ方は3つある。
  1. 値の比べ。ℚ の段までは決まる。
  2. 論理の代金つきの値の比べ。列の段（J.17）。
  3. 名前そのものの比べ。木の同一性で、決まるが値の等しさではない（`[x ? x + 1]` と `[x ? 1 + x]` は違う木、coproduct_spec.md 1037 行）。J.15 の名前と値の食い違いと同じ形。

#### J-5. この節が利用者の主張について言うこと（〔R〕）

- J の定理は、どれも Lean で証明した（`sorry` は 0）。`Classical.choice` が出るのは、ℝ を使う `Reals.lean` と、core の Rat を使う J.16(b) の ℚ の形だけ。

予想「代数の区切りを使った自明な型付けを構文と演算の組で見ることが出来る」について。

「自明」は、木を1回畳むだけで決まることと読める。

- ρ（名前の種類）を与えれば（J.1 の所）、字面の印（2）を葉に、区切り（1）を節に置いた木を、畳み1回で種類が決まる。単一化も制約解きも要らない（J.1）。
- 再帰の名前も、有限の束の上で n 巡で着く（J.2）。
- 区切りの種類の表は区切りそのもので、新しく書く表が無い（J.4）。空白の表は {A, L}² の全単射（J.3(a)）。
- 新しく書く表が要るのは、値を読む演算子だけ。字面の印 × 算術の演算子の表は、単位の取り替えの下の斉次性でほぼ決まり、外れは3つ（J.8）。

決まらない所も、組の形で言える。

- 読む段が決められないのは、A か L の分からない対（J.3(b)(c)）、片側が分からない時に答えが相手に依る行（`!_` が単位の行と、比べの `!_` の行。J.6(c) と J.6 の所）、種類の違う両辺の `|`・`;`（J.5）。そこは値の段へ回る。
- `!_` の行の境目は、`!_` がその演算の吸収元か単位か（coproduct_spec.md 41 行）。吸収元と分かる側があれば読む段が決められ、単位の行は値の段へ回る（J.6(c)）。
- 仕様の読む段と値の段の分担（coproduct_spec.md 1033 行）は、この境目より広く値の段へ回す（`&` の答えも。J.5 の所）。読む段は健全を狙い、意図して不完全（J.6 の所）。

だから予想は、次の形で J に起きた。

- 種類は、区切りと字面の印の組を畳むだけで決まる。
- 決まらない所は、A か L の分からない対と、片側が分からない時に答えが相手に依る行で、値の段が決める。
- 粗い種類の畳みは、表が結合的な演算子（`+`、J.7(b)）の並べ替えで変わらないが、値の畳みは変わる（J.7(c)）。値から取る種類も変わる（J.7 の所）。法則が値の段で崩れるのは、溢れ（Int、J.7(c)・J.13）と丸め（Float、J.20）の所。
- 全域性（どの文脈にも種類が付くこと）は、行の模型の外の口（参照の口・既定値・撒く口）と、値の段の V12 の「まだ」が残る（§5）。

Cantor・Gödel・Lawvere について。

- Cantor の対角線は、不動点の無い写像を名前の段に当てた物（J.21(a)、E.1 の形）。値の段で通すには、二重の名前の尾（0 と 9）を避ける（J.21(b)(c)）。
- Gödel の不完全性も、Cantor・Tarski と同じ Lawvere の形に乗る（〔引〕Lawvere 1969。Turing・Rice は Yanofsky 2003。Lean には起こしていない）。
  - Cantor・Tarski は対偶の向きで使う：不動点の無い自己射があれば、点全射が無い。
  - Gödel の文（対角化の補題）は正の向きで使う：表せること（点全射）から ¬Prov の不動点を得て、無矛盾を足すと不完全性になる。
- Set* の射には不動点の無い物が無い（D.5・E.3）ので、Set* の射だけでは対角線の矛盾（対偶の向き）は組めない。
- でも、値の写像としての `e ; v` には不動点が無い（J.22(a)(b)）。だから嘘つきの文の材料は言語に在り、その解は全域に無い（J.22(e)）か、1つに決まらない（J.22(f)）。
- Sign の答えは、自己参照を矛盾にも作り話にもせず、断り（問10）か行の `!_`（11-19 の決め）に置くこと。どちらもまだ入っていない。今の alpha1 は、同じ実引数の輪を interpret-not-yet で止め、実引数の変わる輪では打ち切りの深さの偶奇で作り話をする（J.22(g)・J.23）。
