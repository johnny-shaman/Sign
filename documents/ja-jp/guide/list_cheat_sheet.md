# リスト操作（文字列操作）チートシート

| 目的 | 操作 | 例 | 結果 |
| ------ | ------ | ---- | ------ |
| 要素数の取得 | `\|\|list\|\|` | `\|\|1 2 3\|\|` | `3` |
| 先頭に要素追加 | `element list` | `0 [1 2 3]` | `[0 1 2 3]` |
| 末尾に要素追加 | `list element` | `[1 2 3] 4` | `[1 2 3 4]` |
| 先頭に文字列を足す（cons） | `string strings` | `` `ab` ts ``（`` ts : `cd` , `ef` ``） | `` [`ab` , `cd` , `ef`] `` |
| 行列に行を足す | `matrix row` | `m [5 6]`（`m : 1 2 , 3 4`） | `[1 2 , 3 4 , 5 6]` |
| リストの結合 | `list1 list2` | `xs ys`（`xs : 1 2`・`ys : 3 4`） | `[1 2 3 4]` |
| 先頭要素の取得 | `list ' 0` | `[1 2 3] ' 0` | `1` |
| 先頭要素の取得 | `0 @ list` | `0 @ [1 2 3]` | `1` |
| 末尾要素の取得 | `list ' -1` | `[1 2 3] ' -1` | `3` |
| 末尾要素の取得 | `-1 @ list` | `-1 @ [1 2 3]` | `3` |
| 残余の取得 | `list ' 1~` | `[1 2 3] ' 1~` | `[2 3]` |
| 残余の取得（1要素でも器） | `list ' 2~` | `[1 2 3] ' 2~` | `3` だけを持つ器（`' 0` で `3`） |
| 残余の取得 | `1~ @ list` | `1~ @ [1 2 3]` | `[2 3]` |
| 残余の取得（位置が識別子の中身） | `list ' @i~` | `i : 1` → `[1 2 3] ' @i~` | `[2 3]` |
| 残余の取得（位置が識別子の中身） | `@i~ @ list` | `i : 1` → `@i~ @ [1 2 3]` | `[2 3]` |
| インデックスで要素取得 | `list ' index` | `[1 2 3] ' 1` | `2` |
| 識別子の**中身**で要素取得 | `list ' @i` | `i : 1` → `[1 2 3] ' @i` | `2` |
| インデックスで要素取得 | `index @ list` | `1 @ [1 2 3]` | `2` |
| 範囲で要素取得 | `list ' [start ~ end]` | `[1 2 3 4] ' [1 ~ 3]` | `[2 3 4]` |
| 範囲で要素取得 | `[start ~ end] @ list` | `[1 ~ 3] @ [1 2 3 4]` | `[2 3 4]` |
| 重複した要素の作成 | `list * count` | `[0 1] * 3` | `[0 1 0 1 0 1]` |
| 重複した要素をリフト | `list ^ count` | `[0 1] ^ 3` | `[0 1 , 0 1 , 0 1]` |
| 1段持ち上げる | `~list` | `~[1 2]` | `1 2` を1行に持つ行列（`' 0` で `[1 2]`） |
| 1段下ろす（フラット） | `list~` | `[1 2 , 3 4]~` | `[1 2 3 4]` |
| n次元配列の構築 | `list , list` | `1 2 3 , 4 5 6` | `[1 2 3 , 4 5 6]` |
| リストの分割 | `list / count` | `[1 2 3 4] / 2` | `[1 2 , 3 4]` |
| 範囲リスト構築 | `[start ~ end]` | `[1 ~ 5]` | `[1 2 3 4 5]` |
| 写像関数 | `[pointfree,] list` | `[* 2,] [1 2 3]` | `[2 4 6]` |
| 選択写像 | `[pointfree,] list` | `[< 3,] [1 2 3]` | `[1 2]` |
| 畳み込み関数 | `[pointfree] list` | `[+] [1 2 3 4]` | `10` |

> [!NOTE]
> **空白は同じ階に積み、`,`・2行以上の括りの改行・前置 `~` が階を上げ、後置 `~` が階を下ろす。**
> 空白で並べた物は、いちばん深い物の階に揃えてから左から積む。数や文字は長さ1の器として積まれるので、
> `0 [1 2 3]` は `[0 1 2 3]`、`m [5 6]` は行が1つ増え、`m 5 6` は長さ1の行が2つ増える。
> 同じ階どうしは平らに繋がるので、`[[1 2] [3 4]]` と書くと `[1 2 3 4]` になる（書いた所に warning が出る）。
> 2次元は `1 2 , 3 4` か、行ごとに改行した括りで書く。
> 1階のリストに付けた後置 `~` は何もしない（知らせも出ない）。
> 長さ1のリストの `^` は冪とぶつかるので、1段上げるときは前置 `~` で書く。
>
> ```sign
> ` 2行の行列
> m : 1 2 , 3 4
>
> ` 評価結果: [1 2 , 3 4 , 5 6]   行を1つ足す
> m [5 6]
>
> ` 評価結果: [1 2 3 4]   1段下ろす
> m~
>
> ` 評価結果: 1 2 を1行に持つ行列   前置 ~ で1段上げる
> ~[1 2]
> ```

> [!NOTE]
> **関数の口にリスト（文字列や、リストを持つ名前も）を渡すと、口は前から要素を取る。**
> `add : x y ? x + y` の `add [1 2]` は `3`。
> 並びの残りを丸ごと1つのリストで受けるのは、最後の括りの仮引数（`f : [~xs] ? …`）。最後でない括りの口へ
> 器のまま渡すときは、呼ぶ側で `pair [xs , ys]` と `,` で区切る。
> 長さの見えないリスト（`~t` で受けた残りなど）を2つ以上の裸の仮引数で受けると、答えは `!_` になり、
> 書いた所に warning が出る（括りの口で受ける）。

> [!NOTE]
> **行を積む再帰の底は、前置 `~` で1段上げる。** 書かないと、いちばん下の1行が1次元のまま残って
> その上の行と同じ階として平らに繋がり、それが上へ順に及んで、全部が平らな `[1 2 3 4 5 6]` になる。
>
> ```sign
> pairs : [a b ~rest] ?
> 	rest : [a b] (pairs rest)
> 	a : ~[a b]
>
> ` 評価結果: [1 2 , 3 4 , 5 6]   2つずつの行に
> pairs [1 2 3 4 5 6]
> ```
>
> 群の数が決まっているなら、リストの分割 `list / n`（n 個の群）でも書ける。`[1 2 3 4 5 6] / 3` は同じ3行になる。

> [!NOTE]
> **リストの反転専用の演算子は存在しない。** リストを末尾から辿る計算は、専用演算子ではなく
> rest記法の位置一般化（[`list_model.md` §2.5](../impl/type/list_model.md#25-rest記法の位置一般化末尾両端からの分割代入)）による
> 末尾からの分割代入で表現する。
> ```text
> ` 末尾からのpop（head=先頭からの残り、tail=末尾要素）
> f : [~head tail] ? ...
> ```
> 明示的なリスト反転が必要な場合は、1次元のリストなら再帰関数（`reverse : [x ~y] ? (reverse y) x`）のように自前で書く。

> [!IMPORTANT]
> **鍵の位置の印は、鍵の字面だけで読みが決まる。** 左辺の型を知らなくても、鍵の読みは書いてある形で決まる。
> 鍵の位置では、印1つに意味は1つ。
>
> - 印の無い識別子は**欄の名前**：`list ' i` は `i` という名前の欄を引くので、List では `!_`。
> - 前置 `@` は**中身**：`list ' @i` は `i` の中身（`i : 1` なら `1`）を添字にして1つ引く。
> - 後置 `~` は**そこから終わりまで**：`list ' 1~` は位置 1 から後ろの切り出し。
> - 両方を付けた `list ' @i~` は、`i` の中身の位置から後ろの切り出し。
>
> 切り出しは段を変えない（長さが1でも器のまま）。空になる切り出しは `!_`。
>
> 構造体を実行時の鍵（名前を中身に持つ識別子）で引く綴りは未決。
>
> ```sign
> p : [
> 	a : 1
> 	b : 2
> ]
>
> ` 評価結果: 1   名前 a で引く
> p ' a
> ```
>
> 構造体の項目は**ブロックの行**（`[…]` の中か字下げ）に1行ずつ書く。欄が1つなら `[a : 1]` も構造体だが、
> `[a : 1, b : 2]` のように1行へ2つ以上並べた綴りは構造体にならない。構造体は空白で並べても欄を繋がず、
> 並びの1要素になる。
