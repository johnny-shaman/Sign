# リスト操作（文字列操作）チートシート

| 目的 | 操作 | 例 | 結果 |
| ------ | ------ | ---- | ------ |
| 先頭アドレスの取得 | `$list` | `$[1 2 3]` | `0x1000` |
| 要素数の取得 | `\|list\|` | `\|1 2 3\|` | `3` |
| 先頭に要素追加 | `element list` | `0 [1 2 3]` | `[0 1 2 3]` |
| 末尾に要素追加 | `list element` | `[1 2 3] 4` | `[1 2 3 4]` |
| 先頭要素の取得 | `list ' 0` | `[1 2 3] ' 0` | `1` |
| 先頭要素の取得 | `0 @ list` | `0 @ [1 2 3]` | `1` |
| 末尾要素の取得 | `list ' -1` | `[1 2 3] ' -1` | `3` |
| 末尾要素の取得 | `-1 @ list` | `-1 @ [1 2 3]` | `3` |
| 残余の取得 | `list ' 1~` | `[1 2 3] ' 1~` | `[2 3]` |
| 残余の取得（1要素でも器） | `list ' 2~` | `[1 2 3] ' 2~` | `3` だけを持つ器（`' 0` で `3`） |
| 残余の取得 | `1~ @ list` | `1~ @ [1 2 3]` | `[2 3]` |
| 残余の取得（位置が識別子） | `list ' i~~` | `i : 1` → `[1 2 3] ' i~~` | `[2 3]` |
| 残余の取得（位置が識別子） | `i~~ @ list` | `i : 1` → `i~~ @ [1 2 3]` | `[2 3]` |
| インデックスで要素取得 | `list ' index` | `[1 2 3] ' 1` | `2` |
| 識別子の**中身**で要素取得 | `list ' i~` | `i : 1` → `[1 2 3] ' i~` | `2` |
| 同上（前置の綴り） | `list ' @i` | `i : 1` → `[1 2 3] ' @i` | `2` |
| 構造体を実行時の鍵で引く | `struct ' k~` | `k : ` `` `b` `` → `p ' k~`（`p` は下の注） | `2` |
| インデックスで要素取得 | `index @ list` | `1 @ [1 2 3]` | `2` |
| 範囲で要素取得 | `list ' [start ~ end]` | `[1 2 3 4] ' [1 ~ 3]` | `[2 3 4]` |
| 範囲で要素取得 | `[start ~ end] @ list` | `[1 ~ 3] @ [1 2 3 4]` | `[2 3 4]` |
| 重複した要素の作成 | `list * count` | `[0 1] * 3` | `[0 1 0 1 0 1]` |
| 重複した要素をリフト | `list ^ count` | `[0 1] ^ 3` | `[[0 1] [0 1] [0 1]]` |
| n次元配列の構築 | `list , list` | `1 2 3 , 4 5 6` | `[[1 2 3],[4 5 6]]` |
| リストの結合 | `list1~ list2~` | `[1 2]~ [3 4]~` | `[1 2 3 4]` |
| リストの分割 | `list / count` | `[1 2 3 4] / 2` | `[[1 2],[3 4]]` |
| リストのフラット | `list~` | `[1 2,3 4]~` | `[1 2 3 4]` |
| 1次元リストのストリーム化 | `list~` | `[1 2 3]~` | `1 2 3` |
| 範囲リスト構築 | `[start ~ end]` | `[1 ~ 5]` | `[1 2 3 4 5]` |
| 写像関数 | `[pointfree,] list or stream` | `[* 2,] [1 2 3]~` | `[2 4 6]` |
| 選択写像 | `[pointfree,] list or stream` | `[< 3,] [1 2 3]~` | `[1 2]` |
| 畳み込み関数 | `[pointfree] list or stream` | `[+] [1 2 3 4]~` | `10` |

> [!NOTE]
> **リストの反転専用の演算子は存在しない。** リストを末尾から辿る計算は、専用演算子ではなく
> rest記法の位置一般化（[`list_model.md` §2.5](../impl/type/list_model.md#25-rest記法の位置一般化末尾両端からの分割代入)）による
> 末尾からの分割代入で表現する。
> ```sign
> ` 末尾からのpop（head=先頭からの残り、tail=末尾要素）
> f : [~head tail] ? ...
> ```
> 明示的なリスト反転が必要な場合は、`reference.md`の再帰関数の例
> （`reverse : x ~y ? reverse y~, x`）のように自前で書く。

> [!IMPORTANT]
> **鍵の位置の `~` は、固定値か識別子かで読みが変わる。** `~` はどこでも「中身を出す」で、
> 変わるのは**何の中身か**である。
>
> - `list ' 1~` は**切り出し**。固定値の中身は自分自身なので「中身を取る」が恒等になり、
>   撒く読みしか残らない。
> - `list ' i~` は**中身を鍵にして1つ引く**。`i` の中身（`1`）が添字になる。前置 `@` を付けた
>   `list ' @i` と同じ射である。
> - `list ' i~~` は**中身を取ってから撒く**。識別子で切り出したいときはこの綴りになる。
>
> 左辺の型を知らなくても鍵の字面だけで決まるので、読めば命令が決まる
> （[`type_system.md`](../impl/type/type_system.md) §3.5 の裁定 2026-09-23）。
>
> 構造体を実行時の鍵で引くときは必ず `struct ' k~` と書く——前置 `@` は連番の綴りなので、
> 名前順に置かれたスロットには当たらず、名指しで断る。名前付きスロットに順序は無いので、
> `p ' k~~` は `p ' k~` と同じ値になる。
>
> ```sign
> p : [
> 	a : 1
> 	b : 2
> ]
> k : `b`
>
> ` 評価結果: 2   k の中身（b）を名前として引く
> p ' k~
> ` エラー: 名前付きスロットへ前置 @ では引けません
> p ' @k
> ```
>
> 構造体の項目は**ブロックの行**（`[…]` の中か字下げ）に書く。`[a : 1, b : 2]` のように
> 1行へ並べた綴りは構造体にならない。
